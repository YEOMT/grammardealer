## 대표 확인 환경
PC 1280×720 또는 1920×1080 / 패드 1024×768 / 스마트폰 844×390, 가시 높이 약 310px를 기존 검사에서 재사용한다. 모든 흐름을 모든 기기에서 곱해 실행할 필요는 없다. 자동화 화면 크기는 실제 기기 검사가 아니다.

## 최소 인계 기록 틀
- 작업 기준 commit / 결과 commit:
- 앱 표시 버전 / 원정·언어 정책 변경 여부(이번 범위는 변경 없음):
- `npm test`:
- `npm run build`:
- 관련 focused browser 검사와 실제 실행 환경:
- 정상 공격 2~3회 및 화면 전환에서 확인한 것:
- 실기기 iPad / iPhone / Android / 카톡·인스타 상태:
- 미완료·NOT RUN·발견한 별도 이슈:
- 대표 화면 3~5장 이내:
- PR / main 병합 / 배포 여부를 각각 구분:

픽셀·시간의 조정값은 기록하되 장식 값 튜닝을 위해 반복 대량 검증하지 않는다. 화면 겹침·입력 잠금·중복 정산은 반드시 별도로 고친다.
