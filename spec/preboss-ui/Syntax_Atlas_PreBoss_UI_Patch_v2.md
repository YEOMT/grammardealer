# Syntax Atlas — 최종 보스 개발 전 소규모 UI 패치 (색상 수정 포함)

> 개정: 대명사 PRONOUN 색상만 진한 파란색으로 변경. 이전 첨부본보다 본 개정본 우선.

## 1. 작업 목적과 범위

현재 정상화된 전투 UI의 배치와 구성을 유지하면서, 최근 합의한 다음 항목만 수정한다.

1. 손패 카드 안의 영어 단어를 세로 중앙정렬한다.
2. 화면 최하단에 5~10px 정도의 작은 여백을 둔다. 기본 적용값은 8px이다.
3. 지역 입장 화면을 배경 중심으로 최소화하고, 상점 화면과 분리한다.
4. 상점을 불필요하게 길지 않은 상품 진열 공간으로 정돈한다.
5. 사용자에게 보이는 화폐 명칭을 ‘골드’로 통일한다.
6. 대명사 카드의 품사 색상을 기존 보라색에서 명사와 같은 파란색 계열의 진한 파란색으로 조정한다.

**새 전투 UI를 설계하거나 과거 패치 전체를 다시 구현하는 작업이 아니다.** 현재 최신 작업본과 사용자 변경을 보존한다. 기존 명세와 충돌하면 이번 범위의 최신 지시만 우선한다. 이미 충족된 항목은 다시 만들지 않는다.

이 문서는 대화에서 합의한 수정 지시다. 현재 저장소를 새로 검사하거나 게임 코드를 수정한 결과 보고서가 아니다. 버전 번호는 실제 작업본을 확인한 뒤 기존 릴리스 정책에 맞춰 정하며, 이 문서를 이유로 원정 버전을 불필요하게 바꾸지 않는다.

## 2. 손패 — 위치와 크기는 유지하고 내부 정렬만 수정

### 2.1 영어 단어의 세로 중앙정렬

- 손패 카드의 상단 품사·점수 영역과 하단 상태·형태 선택·선택 버튼 영역을 제외한 **단어 본문 영역**을 기준으로 영어 단어를 위아래 중앙에 둔다.
- 카드 전체의 정중앙에 단어를 절대 배치하여 다른 정보를 겹치게 하지 않는다. 본문 영역 안에서 정렬한다.
- 기본형·선택형, 짧은 단어·긴 단어에 같은 정렬 기준을 적용한다. 이미 있는 긴 단어 처리 방식은 필요한 범위만 보정한다.
- 일반 창과 전체화면에서 단어가 위나 아래에 치우치지 않도록 한다.
- 기존 카드 외곽 크기·다른 품사의 색상·희귀도 테두리·연마·빙정·봉인 표시를 유지한다. 대명사(PRONOUN)의 품사 색상만 5.5절에 따라 변경한다. 손패를 다시 확대하거나 글자 크기를 일괄 변경하지 않는다.
- 조합대 카드에는 손패용 수정을 무차별 적용하지 않는다. 조합대의 크기·정렬·24장 배치와 기존 타격 연출은 그대로 둔다.

### 2.2 화면 최하단 여백

- 손패가 있는 하단 영역과 화면 바닥 사이에 **기본 8px**의 작은 여유를 둔다. 실제 보이는 값은 5~10px 수준을 목표로 한다.
- 기존 하단 padding을 먼저 확인하여 목표 여백이 이미 있으면 중복으로 더하지 않는다.
- 기기의 safe-area가 있다면 별도의 시스템 안전 영역으로 존중하되, 같은 safe-area를 여러 부모에서 중복 적용하지 않는다.
- 페이지 버튼·교환 조작을 포함한 하단 영역이 바닥에 붙거나 잘리지 않게 한다. 큰 하단 띠나 빈 패널을 만들지 않는다.
- 손패 한 줄 및 필요할 때 페이지 전환하는 방식, 카드 선택·형태 변경·드래그는 유지한다.

## 3. 지역 입장 화면 — 배경 중심의 최소 구성

### 3.1 기본 표시

지역 입장 화면에는 다음만 기본 표시한다.

- 화면을 채우는 지역 입장 배경.
- 지역 이름.
- 짧은 소개 한 줄.
- 하단의 진행 버튼.

몬스터 목록·이름·HP·이모지·그림, 목표 문법 목록, 보스 규칙, 큰 안내 패널은 **지역 입장 화면에서 제거**한다. 접힌 대형 패널로 대신 남기거나 별도의 정보 버튼을 새로 늘리지 않는다. 해당 정보를 보여주는 **기존 매 전투 전 안내는 보존**한다.

기존 배경 자산이 있으면 사용한다. 아직 전용 이미지가 없으면 기존 테마 배경을 유지한다. 이번 작업에서 새로운 배경·몬스터·상인 이미지를 제작하거나 구하기 위해 작업을 늘리지 않는다.

진행 버튼은 배경 중앙을 가리지 않도록 하단에 두고, 브라우저 막대와 안전 영역에 가려지지 않게 한다. 현재 지역에 맞는 문구를 사용한다. 배경 전체를 가리는 불투명 정보 상자를 추가하지 않는다.

### 3.2 상점과의 흐름 분리

- 상점이 있는 지역: **지역 입장 화면 → 상점 화면 → 기존 전투 전 안내/첫 전투**.
- 상점이 없는 지역: **지역 입장 화면 → 기존 전투 전 안내/첫 전투**.
- 이미 이 순서로 분리되어 있으면 화면별 내용만 정리한다. 불필요한 새 상태·중간 화면을 추가하지 않는다.
- 상점 위치·방문 횟수·입장 보너스·무료 지급·전투 순서를 변경하지 않는다.
- 화면 재표시나 저장 불러오기로 상품을 재추첨하거나, 입장 지급과 골드 지급을 반복하지 않는다.
- 기존 상점 진행 상태를 불러왔을 때 입장 화면으로 강제로 되돌리지 않는다.

## 4. 상점 — 상품 중심으로 컴팩트하게

상점은 입장 배경을 감상하는 화면이 아니라 **현재 판매 중인 카드·룬·서비스를 확인하고 고르는 진열 화면**이다.

- 카드·룬 상품의 이미지, 이름, 짧은 효과, 가격, 구매 버튼을 가까운 하나의 묶음으로 배치한다.
- 상품 패널을 남은 화면 높이만큼 늘리지 않는다. 이미지와 가격 사이의 불필요한 빈 공간을 줄인다.
- 상품별 정보 길이에 맞춰 정돈하되, 가격과 구매 버튼의 위치는 읽기 쉽게 맞춘다. 작은 정보 차이를 이유로 모든 상품을 거대한 높이로 통일하지 않는다.
- 연마·제거 서비스는 상품 진열과 구분된 간결한 영역에 둔다. 보유 골드는 상단, 상점 나가기 버튼은 하단에서 찾기 쉽게 유지한다.
- 카드의 글자·설명이 카드 밖으로 튀어나오지 않게 한다. 긴 상품 설명은 상품 설명 영역에서 줄바꿈하고, 카드 자체를 가로로 늘이거나 핵심 단어를 지나치게 작게 줄이지 않는다.
- 기존 색감·버튼·카드 디자인을 재사용한다. 새로운 대형 장식, 상인 그림, 빈 상인 전용 패널, 입체 선반 등 별도 아트 작업은 추가하지 않는다.
- 현재 상품 수에 맞는 배치를 사용한다. 작은 화면의 기존 페이지 방식이나 보조 영역 내부 스크롤은 필요에 따라 유지하며, 넘침을 단순히 잘라 숨기지 않는다.
- 상품 풀·희귀도·가격·강화·제거 비용·구매와 취소 규칙·공개 상품 고정은 전부 유지한다.

## 5. 화폐 표시 — ‘골드’로 통일

사용자에게 보이는 화폐 문구를 다음처럼 통일한다.

| 기존 표시 | 변경 표시 |
|---|---|
| 재화 | 골드 |
| 보유 재화 | 보유 골드 |
| 재화가 부족합니다 | 골드가 부족합니다 |
| 건너뛰기 · +2 재화 | 건너뛰기 · +2 골드 |

전투 상태, 상점 가격·잔액, 보상, 안내, 툴팁, 확인창·오류 메시지 등 실제 화폐를 뜻하는 표시를 확인한다. ‘자원형 룬’ 등 다른 의미의 표현까지 일괄 치환하지 않는다.

골드 양·가격·경제 규칙은 변경하지 않는다. 내부 `gold` 필드, 저장 구조, RNG, API 계약이나 과거 기록을 불필요하게 수정하지 않는다.

## 5.5 대명사(PRONOUN) 품사 색상 변경 — 학습 안내 개선

학생들이 명사·대명사를 주어/목적어를 만드는 **파란색 계열 카드**로 인식하고, 이어서 **빨간색 동사 카드**를 배치하도록 안내할 수 있게 한다. 이번 변경은 시각적 품사 표현에만 적용한다.

| 품사 | 현재 코드의 색 | 변경 후 | 조치 |
|---|---|---|---|
| NOUN / 명사 | `#6AA5D4` | `#6AA5D4` | 밝은 파란색 유지 |
| **PRONOUN / 대명사** | `#AE8BD1` | **`#3979BC`** | **기존 보라 → 진한 파란색** |
| VERB / 동사 | `#D56E65` | `#D56E65` | 빨간색 유지 |
| DETERMINER / 한정사 | `#B09BC1` | `#B09BC1` | 보라색 유지 |

- 핵심은 **명사=밝은 파랑, 대명사=진한 파랑, 동사=빨강, 한정사=보라**이다. 대명사는 명사와 한 계열로 인지되면서도 두 품사를 구별할 수 있어야 한다.
- CSS의 공통 품사 변수 `--pronoun`와 그 변수를 참조하는 카드 표시를 일관되게 수정한다. 별도 하드코딩이 있다면 같은 팔레트로 정리한다.
- 손패·조합대·도감·사전·카드 미리보기·선택/드래그·희귀도 테두리에서 대명사의 품사 강조색이 서로 충돌하지 않게 한다. 품사 텍스트 라벨은 유지해 색에만 의존하지 않도록 한다.
- 배경과의 명도 대비를 실제 화면에서 확인한다. 선택·연마·봉인·희귀도 표시를 대명사 색으로 덮어쓰지 않는다.
- **단어·형태·품사 판정·문형·카드 점수·게임 규칙·시드·저장 데이터는 전혀 변경하지 않는다.** 기존 저장 카드도 새 화면에서 진한 파랑으로 표시한다.
- 이 변경 때문에 새 아트 자산, 새 카드, 추가 문법/튜토리얼이나 대규모 UI 수정은 하지 않는다.

## 6. 변경하지 않을 것

- 전투 화면의 헤더, 몬스터, 좌측 기능 패널, 중앙 조합대, 우측 룬 패널, 하단 손패의 기본 배치.
- 조합대·손패의 기존 외곽 크기, **대명사를 제외한 품사 색상**, 문장 및 손패 한도, 카드/룬 성능, 문법 판정, 점수, HP, 기믹, 턴과 드로우.
- 기존 ‘턴 넘기기’, ‘조합대 비우기’, 버리기 버튼 위치 등 이미 완료한 편의성 수정.
- 전체화면·가로 플레이 정책·사전·도감·저장·보상·카드 보존·공격 연출.
- 최종 보스 3페이즈, 랭킹, 해방 보너스, 새로운 룬 봉인·단어 봉인 등 논의 중인 콘텐츠.
- 새 프레임워크·UI 시스템 도입, 광범위한 CSS 재작성, 게임 엔진 리팩터링.

## 7. 구현과 최소 확인

**작은 구현 → 대표 화면에서 직접 확인 → 인계**로 끝낸다. UI 미세 폴리싱을 이유로 작업을 계속 확장하지 않는다.

확인은 아래 네 묶음이면 충분하다.

1. **손패:** 대표 PC 창모드에서 짧은/긴 단어가 섞인 손패를 확인하고 전체화면을 한 번 전환한다. 단어 세로 중앙, 하단 약 8px, 기존 카드 선택·페이지 이동이 정상인지 본다. 태블릿 가로 크기에서도 한 번 확인한다. 실제 기기가 없으면 에뮬레이션임을 명시한다.
2. **입장과 상점:** 상점이 있는 지역 한 곳과 없는 지역 한 곳에서 진행을 확인한다. 입장 화면은 최소 요소만 있고, 기존 전투 전 정보는 남아 있는지 본다. 화면 이동만으로 상품·골드·입장 지급이 중복 변경되지 않는지 확인한다.
3. **상점과 골드:** 상품·가격·버튼의 가까운 배치와 카드 글자 넘침을 확인하고, 대표 구매 동작 한 번으로 표시와 실제 잔액이 일치하는지 본다. 화면·메시지에 남은 화폐 ‘재화’ 표기를 검색한다.
4. **품사 색상과 기본 검사:** 대명사가 명사보다 진한 파랑으로 표시되고 한정사는 보라로 유지되는지 손패·조합대에서 육안 확인한다. 기존 카드/점수 동작이 유지되는지 확인한다. 저장소 작업 규칙에서 요구하는 필수 검사와 빌드를 최종 변경본에서 한 번 실행한다. 같은 코드에서 통과한 검사를 이유 없이 반복하지 않는다. 이후 코드가 바뀌면 영향을 받는 검사만 다시 확인하고 저장소 필수 규칙을 따른다.

이번 패치에 전체 원정 완주, 다수 seed, 전 브라우저·전 기기 조합, 대량 캡처, 별도 성능 벤치마크, 방대한 신규 테스트 모음을 요구하지 않는다. 저장/상품 상태를 실제로 수정한 경우에만 해당 핵심 동작을 좁게 확인한다.

버튼 잘림·클릭 불가·카드 소실·상품 재추첨·골드 중복 지급·저장 오류 같은 기능 결함은 해결한다. 미세한 색감·간격은 남은 사항으로 기록하고 사용자 플레이 피드백으로 다듬는다. 미실행 검사는 PASS라고 보고하지 않는다.

## 8. 인계

현재 작업 브랜치와 사용자 변경을 보존하여 수정한다. 아직 미병합인 동일 작업이 있으면 그 위에서 이어가고, 이미 병합됐으면 최신 main에서 별도 패치 브랜치로 진행한다. 코드 전체를 과거 버전으로 덮어쓰지 않는다.

보고서는 **변경 내용, 실제 실행한 검사 결과, 대표 화면 소수, 남은 문제, 브랜치/PR** 정도로 간단히 쓴다. 사용자 승인 없이 main 병합·공개 배포·Pages 설정 변경을 하지 않는다.

**완료 기준: 현재 전투 배치가 그대로인 상태에서 손패 단어와 하단 여백이 정돈되고, 대명사 품사 색이 진한 파란색으로 표시되며, 입장 화면은 풍경 중심이고, 상점은 컴팩트한 진열 공간으로 분리되고, 화폐 표기가 골드로 통일되어 플레이 가능한 상태.**
