# Syntax Atlas 0.12.2 안정화 인계

**디자인 변경 없이 접속·터치 확대·드래그·복귀·기존 오디오 안정화만 구현한다.**

## 전달 방법

이 ZIP 하나와 `Syntax_Atlas_0.12.2_START_PROMPT.txt` 내용을 Codex에 전달한다. 현재 Git 저장소가 구현 기준이다. 과거 전체 명세를 다시 실행하지 않으며, 기존 이미지·BGM도 다시 업로드하거나 교체할 필요가 없다.

## 파일

| 파일 | 역할 |
|---|---|
| Syntax_Atlas_0.12.2_Device_Stability_Spec.md | 전체 구현 명세 |
| Syntax_Atlas_0.12.2_Device_Stability_Spec.txt | 위 명세와 동일한 UTF-8 텍스트 |
| Syntax_Atlas_0.12.2_START_PROMPT.txt | 작업 시작 지시 |
| CHECKLIST.md | 여섯 흐름 중심의 검증·인계 표 |
| SOURCES.md | 소스 확인과 브라우저 문서, 설계 판단의 구분 |
| MANIFEST.json | 위 파일의 SHA-256과 크기 |

## 범위 주의

이 ZIP에는 게임 소스, 에셋, 실행 테스트 결과가 없다. 코드가 확인된 것과 실제 기기에서 소리가 난다는 것은 다르다. 실기기 확인은 수행한 환경만 기록한다.

스마트폰 화면 재배치·폰트 확대·패널 접기·새 제어 UI·새 저장 기능·미등록 지역 BGM 추가는 이번 범위가 아니다. 기존 작은 화면 폭 제한을 숨기기 위해 전역 스크롤을 막지 않는다.

앱 표시 버전은 0.12.2, 게임 콘텐츠 계약은 기존 0.12.1 유지가 기본이다. 이미 0.12.2가 사용 중이면 태그를 덮어쓰지 말고 충돌을 보고한다.
