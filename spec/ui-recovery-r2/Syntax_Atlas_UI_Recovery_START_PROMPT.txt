첨부한 「Syntax_Atlas_UI_Recovery_Codex_Package.zip」의
「Syntax_Atlas_UI_Recovery_Brief.md」 리비전 2.0을 이번 UI 작업의 우선 지침으로 사용하라.

기존 0.10.1 구현과 사용자 변경을 보존하면서 현재 작업 상태부터 이어서 수정하라.
0.10.0은 UI 복원 참고이며, 과거 소스로 프로젝트 전체를 덮어쓰지 마라.

승인 시안은 공간 배분과 시각적 위계의 기준이다.
시안 속 임시 문법·룬·몬스터·구두점 카드·누락된 행동 버튼을 그대로 구현하지 마라.
실제 게임의 카드 구성과 규칙은 유지하라.

PC 일반 창과 태블릿 가로에서도 로비·적 정보·점수·좌우 기능이 정상적으로 보여야 한다.
조합대는 손패와 같은 카드 너비·영어 글자 크기로, 한 줄 최대 12장씩 두 줄만큼만 확보하라.
각 줄을 독립적으로 중앙정렬하고 남는 화면 공간으로 조합대를 무한히 늘리지 마라.
전체화면은 정상 UI를 보기 위한 필수 조건이 아니다.

UI 복원과 실제 제출 한도 24장 변경을 별도 커밋으로 다루고,
기존 저장·문법·룬·HP·획득 규칙·보스·47전투 경계를 보존하라.

본명세의 핵심 확인 10가지와 저장소 필수 테스트·빌드를 수행하되,
미세 디자인이나 모든 기기 조합의 반복 검증으로 인계를 지연하지 마라.
실제 브라우저 대표 캡처, 변경 사항, 실행 결과와 남은 문제를 간결하게 보고하라.
계획만 세우지 말고 실제 수정과 플레이 가능한 결과를 인계하라.
main 자동 병합·공개 배포는 하지 마라.
