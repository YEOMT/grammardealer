# v0.15.1 R2 인수 조건 체크리스트 — `사전`만 유지

기존 R1의 `카드` 통합창/`내 덱` 탭 조건을 **폐기**하고 R2 조건으로 대체하였다.
현재는 구현 전 기준표이며 모든 항목은 **NOT RUN**이다. 구현자가 결과·근거·환경을 채운다.

## 실제 검사와 기록
- 사전 단독 진입과 `내 덱` 메뉴 제거 확인, 하단 카드 묶음 분리 확인
- 단위/데이터: 명령·종료 코드·검증 버전
- 브라우저: 엔진/가시 영역·핵심 경로
- 스크린샷: 실제 렌더·검사 결과
- 실기기: iPad/iPhone/Android/인앱 및 청취를 따로 표시
- 자연 완주: 이번 요구 범위 아님. 지정 상태 검사를 자연 완주라고 부르지 않는다.
