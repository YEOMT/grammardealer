# 패키지 자체 검증

검증 범위: **문서·자료 내부 일관성**. 게임 구현/문법 파서 실행/브라우저/실기기/자연 원정 시험은 실행하지 않았다.

확인 완료: HP19개와 골렘260×3=780, 신규룬10종 및 일반2/고급5/희귀3, 각3레벨·동명사/4형식토파즈ID분리,194:97:9와Stage4상점조건,34개합성산술기대값,130개인수조건의유일ID/미실행상태,문법44/추첨18/표시18/viewport12/상태8개계획자료의형식과ID,시각강도증가/상한,문서파일과JSON구문.

이 검증은 `verify_package.py`로 재현할 수 있다. manifest 생성 후에는 파일별 SHA256과 바이트 수까지 검사한다. 어떤 자료도 ‘실제 게임 테스트 PASS’로 표시하지 않는다.
