# Codex / Work 시작 프롬프트 — Syntax Atlas v0.10.1

## 작업 기준

YEOMT/grammardealer의 최신 main과 현재 브랜치·HEAD·미커밋 작업을 먼저 확인하라. 작성 시 기준 main은 f09d4537b3bfa28d2736045944da363c8a04abfc이나, 그 커밋으로 강제 되돌리지 마라. 옛 ZIP이나 배포 번들로 현재 소스를 덮어쓰지 마라.

AGENTS.md, README, 아키텍처/인계 문서와 ZIP의 본명세, 02_RUNE_RULES_KO.md, 03_UI_GAMEFEEL_KO.md, 04_ACCEPTANCE_KO.md, 05_TEST_MATRIX_KO.md, 06_SOURCES_AND_DECISIONS_KO.md를 모두 읽어라. data/와 fixtures/는 설정 의도와 테스트 기대자료이지 이미 구현·통과한 결과가 아니다.

## 구현 범위

1. 새 0.10.1 원정의 Stage 2 HP는 200/270/360/750, Stage 3은 300/320/360/400/780(골렘 260×3), Stage 4는 500/530/570/600/1000, Stage 5는 640/680/740/800/1300으로 적용하라. 일률적인 10% 하향으로 치환하지 마라.
2. 신규 룬 10종을 추가하라. 일반 화석·석영은 고정 가산이며 +30/+50/+70은 검증 초깃값이다. 고급 가넷·백금·라피스·아쿠아마린·동명사 토파즈, 희귀 흑요석·아다만티움·미스릴은 명세의 3레벨 배율을 따른다. 나머지 제안 룬은 보류한다.
3. 기존 4형식 토파즈를 덮어쓰지 말고 별도 ID와 ‘4형식/동명사’ 부제로 구분하라. 기본 문법 배율의 중복과 서로 다른 룬의 적법한 시너지를 구분하고, 오류·미해금 근거로 발동시키지 마라.
4. 일반/고급은 Stage 1부터 후보 자격을 열어라. 희귀는 일반전 및 첫 소개 보상에서 제외하고, 지역 보스 보상과 Stage 4 입장 상점부터만 허용하라. 기존 다이아몬드와 희귀 레벨업도 같은 규칙을 따른다. 첫 실제 상점은 Stage 2이며 새 Stage 1 상점을 만들지 마라. 기존 194:97:9 가중치와 가격, 공개 offer/RNG 고정을 보존하라.
5. PC·태블릿·모바일 전체화면 옵션과 실제 가시 viewport 맞춤을 구현하라. 주소창이 보이는 태블릿에서도 페이지 스크롤 없이 핵심 전투 조작이 가능해야 한다. 고정 최소 너비/높이와 모달을 함께 정리하되, overflow:hidden이나 전역 축소로 잘림·읽기 불가를 숨기지 마라. 미지원 브라우저는 정상 fallback하고 게임 상태를 보존하라.
6. 문법/룬 점수 적용 시 그 효과의 실제 제출 근거 카드에 짧은 탄성 ‘또잉’ 반응을 주어라. 콤보 문구와 숫자를 선명하게 하고, 한 공격 안의 실제 문법/룬 콤보 누적에 따라 글로우·파티클을 점진 강화하라. 등급/레벨별 룬 발동 차이를 기존 룬에도 적용하라. 카드 기본점수·flight·final 재표시를 중복 카운트하지 마라.
7. 기존 읽기 시간과 속도, 효과 끄기/모션 감소, 성능 상한, 근거 ID, 중단 복구, 단일 정산을 지켜라. 연출이 점수·HP·RNG를 변경하지 않게 하라.
