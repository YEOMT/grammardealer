## 특히 주의

일반 화석·석영의 **+30/+50/+70**은 아직 실측 전인 가산량 제안이다. 기존4형식 토파즈와 새 동명사 토파즈는 **같은 룬이 아니다**. 이름 부제를 임시로 구분한다. Stage5 일반전은 사용자의 절대 HP값을 적용하며, 전체를 10% 하향하지 않는다.

희귀는 일반전 보상에 나오지 않고, **Stage4 입장 상점(두 번째 상점)**부터 상점 후보가 된다. 기존 다이아몬드와 희귀 레벨업도 포함한다. 첫 Rune 소개의 기존 예외는 유지한다.

전체화면 API가 지원되지 않아도 화면 맞춤을 적용한다. PC/태블릿의 동시 카드 식별과 아주 작은 휴대전화의 명시적 페이지 예외를 구분한다. 사전·저장 접근은 유지한다.

검증자료에는 실행 결과가 없다. 실제 파서/브라우저/실기기/자연 원정 결과를 각각 수행하고 작성해야 한다. `verify_package.py`는 파일 및 산술 기대자료의 내부 검증만 수행한다.

## 원격 작업 경계

별도 작업 브랜치와 PR까지 진행한다. main 직접 push·자동 병합·Pages 설정 변경·공개 배포는 별도 승인 대상이다. 권한이 없으면 로컬 작업·검증 결과와 오류를 인계한다.
