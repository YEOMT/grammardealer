# v0.10.1 전체화면·반응형·Game Feel 상세 계약

## 1. 한 화면의 의미

핵심은 **브라우저를 스크롤하지 않고 적/턴/문장/손패/공격/준비/교환을 조작**하는 것이다. 전체화면 버튼을 붙이는 것만으로 완료하지 않는다. 주소창이 보이는 태블릿에서 먼저 확인한다.

원래 크기 카드의 모든 설명을 모든 휴대전화에서 동시에 표시한다는 보장은 하지 않는다. PC/태블릿은 최대사본 동시 식별을 우선 검증한다. 매우 작은 휴대전화/분할창에서 정보 접기·명시적 카드 페이지가 필요하면 예외로 기록한다. 단순 숨김/터치 불가/무제한 축소는 허용하지 않는다.

상점·보상·로비·지역 소개·완료 화면도 주 행동과 선택지를 화면 안에서 사용할 수 있게 한다. 긴 사전/기록/대상 선택 리스트의 내부 스크롤은 예외다. 페이지 스크롤을 막으면서 모달 내부까지 막지 않는다.

## 2. 레이아웃 우선순위

1. 적 HP/기믹, 남은 턴/교환, 공격/준비/교환 확인.
2. 조합대의 순서·선택 형태·손패 단어와 카드 조작.
3. 사전·저장·내 덱 접근, 장착 룬의 이름/레벨/순서 요약.
4. 학습 안내·이번 콤보·점수. 사후 상세는 별도 모달로 확장.
5. 장식 적 크기·배경 여백·상시 긴 룬 설명·로고는 먼저 압축한다.

현재 대화에서 사전/저장 활용이 실제 학생의 재도전에 도움을 주었다는 관찰을 보존한다. 이를 작게 숨겨서 조작을 늘리지 않는다.

## 3. 브라우저 API와 가시 영역

Fullscreen API는 사용자의 명시적 입력에서 요청하고 Promise 성공/실패 및 fullscreenchange를 처리한다. [W01] 안정 루트가 모달/FX 전체를 포함해야 한다. documentElement 또는 동등한 영구 앱 래퍼가 적합한지 실제 DOM을 확인한다.

실제 가용 높이를 `100dvh`와 지원 탐지 fallback으로 사용하고, 주소창/키보드 차이가 남는 환경에서 VisualViewport를 보조한다. [W02][W03] safe-area를 중복 차감하지 않는다. CSS viewport와 디바이스 하드웨어 픽셀을 혼동하지 않는다.

ResizeObserver/resize/visualViewport 이벤트를 한 프레임에 합쳐 적용한다. 단순 resize를 위해 전체 RunController를 재생성하지 않는다. 핀치 zoom의 visual viewport 변화를 자동 ‘원상복구’와 혼동하지 않는다. 문자 입력 시 키보드 축소와 문서 확대 상태는 따로 다룬다.

Fullscreen 미지원/권한 거절/iframe 제약은 정상 fallback 상태다. 주소창 없는 실행이나 화면회전 잠금 지원을 필수 전제로 만들지 않는다. 설치를 요구하거나 랜덤 브라우저 내부 API를 쓰지 않는다.

## 4. 탄성 카드 반응

한 문법 점수 이벤트의 evidence 카드 집합을 확정하고, 같은 물리 사본은 집합 안에서 한 번만 반응한다. 카드 바깥 배치/선택 transform과 다른 내부 시각 레이어를 애니메이션한다.

추천 키프레임: 0%원래 → 18%작게압축 → 45%들림/작은오버슈트 → 72%반대방향으로감쇠 → 100%원래. 280ms/scale상한1.045/회전±1.2도/위로4px는 시작값이다. 강도는 누적·등급·레벨로 제한적으로 보강하고 문장의 위치·읽기방향은 유지한다.

다수 카드의 반응은 전부 한 덩어리 흔들기보다 근거 집합의 짧은 순차감으로 표현한다. 16장의 전체 반응을 16×전체duration 직렬 재생하지 않는다. groupStagger는18ms, 지연상한90ms로 시작한다.

RUNE_FLIGHT는 예고, SCORE는 실제 숫자 적용이다. **한 eventId에서 combo increment와 spring group을 한 번만** 만든다. 시각적으로 비행부터 예고할 수 있지만 다시 같은 이벤트를 세면 안 된다.

### 매핑 예

- 진행: 해당 aux be + -ing lexical VP 카드.
- 과거: 해당 유한 동사구 카드. 문장 내 다른 과거/가정법 역할과 혼동하지 않음.
- 동명사/to부정사: 해당 구와 역할 근거. 아무 -ing/to 카드 전체가 아님.
- 수동태: 해당 수동 동사구 및 판정상 필요한 근거.
- 관계절: 실제 선행사와 그 관계절 사본. 소유하지 않은 생략 마커는 가짜 카드로 만들지 않음.
- 주절1~5형식: 현재 주절의 실제 성분 카드. 다른 절은 제외.
- 룬: 해당 rune event에 연결된 실제 증거사본. 문법과 룬이 다른 실제 이벤트에서 같은 근거를 사용하면 각 단계에서 다시 반응 가능.

## 5. 콤보 카운트 정의

시각 카운트는 각 공격의 확정 score timeline에서 계산한다. `after > before`이고 (양수 ADD 또는1초과 MULTIPLY), 출처가 문법/룬의 인정된 의미 단계일 때만 증가한다. 카드베이스·정확성·저항·보스·지역·final SET/재표시·flight·미발동은 제외한다. 기존 의미단계의 완전문장/주절/구문/수식은 포함한다.

같은 id 재전달은 증가0. 기존 사본별 룬에 별도 eventId가 있으면 그 실제 가산 이벤트는 각각1이다. 신규10룬은 once-per-attack이므로 효과 자체를 증식시키지 않는다. 숫자의 크기와 콤보 누적은 다른 축이고, 저항/예견으로 피해0이 되었더라도 앞의 실제 점수 이벤트를 삭제하지 않는다. 대신 마지막 피해0 원인은 분명하게 표시한다.

## 6. 글자와 숫자 모두 점진적으로 장식

`data/gamefeel_initials.json`의 시각 tier는1~2/3~4/5~7/8~11/12+다. tier 내부의 변화도 보간하고 상한 이후에는 더 커지지 않는다. 이는 점수 배율이 아닌 렌더링 정책이다.

문법/룬 이름과 +/×수치는 고대비인 중심 레이어에, 글로우/파티클은 바깥 레이어에 둔다. 글자 내부를 흰색으로 날리거나 모션 중 매 프레임 폭을 바꾸지 않는다. 레이아웃은 가장 큰 표시 상태의 공간을 미리 확보한다.

일반 → 고급 → 희귀 및 Lv.1→2→3 차이는 효과양식·외곽선·입자량·짧은 밝기곡선으로 나타낸다. 이 변화 때문에 전체 공격 길이가 계속 늘어나지 않아야 한다. 태블릿의 반복 플레이에서는 긴 연출보다 분명한 타격과 짧은 안정 구간을 우선한다.

최종공격력이 커도 보스가 막았다면 막힘 연출을 따른다. 룬 점수의 화려함이 실제 HP 감소/처치와 모순되지 않는다.

## 7. 성능 예산과 접근성

권장 시작 상한: 동시입자 PC48/휴대형24. 이벤트마다 상한만큼 추가하는 것이 아니라 화면 전체 활성 수를 제한한다. 1공격 종료, 취소, background, render 교체 후 FX node/animation/timer/RAF가 정리되어야 한다. particle pool/단일 overlay 등 최소 구조를 사용한다.

Web Animations 또는 CSS transform/opacity와 한 번 측정한 좌표를 우선한다. score 글자/카드 주변 대형 blur를 매 프레임 다수 새로 계산하지 않는다. 외부 폰트/대형효과 라이브러리 로딩을 늘려 체감만 늦추지 않는다.

프레임60fps는 목표이지 보장으로 보고하지 않는다. 같은 fixture/viewport/기기에서 효과 끔/켬의 frame interval p50/p95, 50/100ms 초과 구간, 활성 FX 수, 30회 공격 전후 잔존 노드를 비교한다. 실제 기기를 확보하지 못하면 에뮬레이션 성능과 구분한다.

motion 감소/효과 끄기는 카드 바운스·회전·입자 대신 정적 테두리/대비 강조로 바꾼다. 필수 글자/숫자는 유지한다. 강한 전면 섬광/빠른 반복 점멸을 금지한다. 고콤보 캡처/동영상에서 안전성과 읽기 시간을 함께 검토한다. [W04]

## 8. 상태 안전

Fullscreen 진입/종료, 회전, DPR 변경, 주소창 표시, 사전 검색키보드, 탭복귀는 게임 명령이 아니다. RNG/턴/HP/보상/빙정/룬레벨을 바꾸지 않는다.

애니메이션 완료 콜백에서 점수나 HP를 재계산하지 않는다. 기존 watchdog과 단일 FINISH_PRESENTATION 정산을 보존한다. user zoom·문장선택·드래그를 위한 기존 transform/style 값을 정리 과정에서 무차별 초기화하지 않는다.

필수 UI 검증: 다이아몬드+3개의신규룬, 16카드 긴 문장, 최대손패14, 1형식 짧은 문장, 장문 콤보 라벨, 사전/저장/보상모달, 미스릴이예견을우회하는공격, 예견차단공격, 도서관장회복, 마지막턴격파, 연출중화면전환.
