# 최신 UI 결정에 따른 대체표

이 표는 현재 0.10.1 명세와 그 뒤의 대화 제안을 조정한다. 완료된 게임 코드를 원복하라는 뜻이 아니다.

| 이전 내용/오해 가능 지점 | 최신 기준 | 처리 |
|---|---|---|
| 원본 본명세8.2: 휴대전화 세로에서도 플레이 허용 | 휴대전화/태블릿은 가로 플레이만, 세로는 회전 안내 | 관련 UI·테스트를 대체 |
| 원본 세로 viewport에서 정상 전투 조작을 요구 | 세로 입력 차단·복귀 상태 보존을 검사 | 구 조건 SUPERSEDED |
| 매우 작은 화면의 조합대 페이지 전환 예외 | 조합대는 문장 전체가 행으로 이어짐 | 조합대 페이지를 기본/예외 해법으로 사용하지 않음 |
| 앞선 제안의 최대 2행 | 3행 이상도 허용, 세로 추가 압축 | 2행 상한 제거 |
| 공간을 채우는 넓은 조합대 카드 | 손패 너비·영어 글자 유지 | 과도한 stretch 규칙 제거 |
| 많은 카드에서 조합대만 width/font 축소 | 행 수/세로 여백으로 해결 | count 기반 가로/영어축소 제거 |
| 카드 동일 크기=높이도 무조건 동일 | 너비·영어는 같고 조합대 높이는 압축 가능 | 상태/버튼 최소높이 보존 |
| 이전 header 중앙 로고/한쪽 스테이지 | 왼쪽 로고·화면 정중앙 스테이지·오른쪽 전체화면/로비 | 배치 변경 |
| 전체화면=브라우저마다 자동가로회전 보장 | 지원환경 요청, 실패면 직접회전 안내 | API 실패를 정상 fallback |
| 몬스터 무대에 넓은 고정비율 예약 | 작은 교체 여지만, 조합대 우선 | 대형 미술/레이아웃 재설계 제외 |
| 좌우 정보를 반드시 상단으로 전면 이동 | 지금 구성 보존, 좁은 화면에만 국소 reflow | 전면 재배치 불필요 |
| 다음 UI 작업에서 전 스테이지 팔레트 새 설계 | 기존 테마 대비 검수만 | 신규색/원화 기획은 보류 |
| 새 동명사 토파즈/4형식 부제 병존 | 새 동명사는 자수정, 기존4형식은 토파즈 | 이름·툴팁·테스트 추적 동기화 |
| 패널 밖 넘침은 clipping으로 숨김 | 내용·클릭영역 자체가 안에 들어옴 | 사전/도감/저장 접근 보존 |

이 파일에서 변경하지 않는 규칙은 원래 0.10.1에 따른다. 특히 HP·신규10룬·희귀경로·기존문법·47전투·버전격리·사전/저장·GameFeel의 계산독립성은 유지한다.
