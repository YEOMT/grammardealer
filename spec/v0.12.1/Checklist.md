# 실행·인계 체크리스트 — 결과는 구현자가 작성

현재 상태는 모두 미실행이다. 작성자는 실제 게임 테스트를 실행하지 않았다.

| 묶음 | 완료 기준 | 결과/근거 |
|---|---|---|
| A | 최신 소스/미커밋 변경 보존, 후속 번호·정책 연결 | NOT RUN |
| B | look→smile(SV), room 제외·game 유지, 확정 8개+필요시 of 연결 | NOT RUN |
| C | 최신28장·동사8장, 신규 획득 경로, 구 저장/공개 보상/RNG 보존 | NOT RUN |
| D | hard/fast/well·answer/watch/show·too 역할 정확·중복효과 없음 | NOT RUN |
| E | try/remember to·ing 보존, notice/remember/discover that절 | NOT RUN |
| F | possible/necessary/clear·for/of 구문 및 실제 보너스 연결 | NOT RUN |
| G | 원형 라벨만, p.p./버튼 간격/손패 여백/준비화면 보존 | NOT RUN |
| H | 실제 연속 공격·viewport/전체화면·빠른 배속에도 집결/돌진 표시 | NOT RUN |
| I | 일반 크기 유지·보스 약2배 목표·기본/피격 비침범 | NOT RUN |
| J | BGM fade-out→종료→1초쉼→fade-in, 취소/음량/효과음 유지 | NOT RUN |
| K | test / validate:data(있으면) / build / 관련 브라우저 검사 | NOT RUN |
| L | 기기 청취/실기기 범위와 배포 상태를 사실대로 구분 | NOT RUN |

단위검사 목록을 인수조건 개수로 부풀리지 않는다. 캡처2~4장과 변경요약, 실제 테스트 결과로 충분하다. 실패한 경계는 숨기지 말고 해당 부분만 수정·재검사한다. 전투50회·대량 seed·새 테스트 UI는 요구하지 않는다.
