## 필요한 짧은 실행 흐름

1. 단위검사: GRAMMAR_CASES의 정상/오류/미지원 및 계수·순서·해금·HP/영수증을 검사한다.
2. PC 또는 패드 가로: 15전투 도구해금 → 배치/이동/회수 → 24단어+쉼표 → 실제공격.
3. 스마트폰 가로: 페이지와 독립된 도구 → 8열 줄경계 → 스크롤/형태선택 → viewport축소/복구 → 공격. 실기기 없으면 에뮬레이션으로 명시한다.
4. 지정43~47 흐름: 두 분사구문과 두 가정법 안내 → 세실 임의순서 → HP1에서 마지막실 해제/격파 → 저장왕복. 자연전투 완주로 기록하지 않는다.
5. 지정48/49: 가능분사과제 하나, 불가능후보제외, 주절시제오인정방지. 50의 추가장벽없음과 기존결전흐름 확인.
6. 최종 기본테스트·언어데이터검증·빌드. 실패부분만 고쳐 관련검사를 다시 실행한다.

배율/감점의 재미와 실제 난도는 사용자 플레이 피드백으로 후속 조정한다. 이를 위해 지금 대량 시뮬레이션이나 이펙트 시안을 반복하지 않는다.
