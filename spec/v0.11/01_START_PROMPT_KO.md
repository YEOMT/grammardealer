# Syntax Atlas 0.11.0 — 최종 3페이즈·50전투 패치 시작 지시

첨부한 「Syntax_Atlas_0.11_50Battles_Handoff.zip」을 이번 구현 계약으로 사용하라.
이는 구현/검증용 소스가 아니라 명세 패키지다. JSON은 기대자료이지 게임 로직을 대체하는 정답표가 아니다.

먼저 최신 main과 현재 사용자 변경을 확인하고 AGENTS.md를 읽어라.
조회 기준 main은 cb1958f66dda4e4cd320c7b03e661d7a8cb41cf4이며,
앱 패키지는 0.10.4, 원정 계약은 0.10.2였다. 실제 작업 기준은 최신 정상 소스다.
과거 ZIP으로 덮어쓰거나 UI를 재설계하지 말고 현재 기능을 보존하라.

핵심 구현:
1. 새 0.11 원정만 기존47전투 뒤에 48 Surface Structure HP5000,
   49 Deep Structure HP6000, 50 Universal Grammar HP10000을 연결한다.
2. Surface는 서로 다른 유형2개를 순차출제하는 2겹 방어막이다.
   유형은 주절1~5형식 / 수동태·to부정사·가주어진주어·관계절·가정법 / 보유동사.
   한 공격에 한 겹만, 남아 있으면 HP1 보호, 마지막 해제 공격은 처치 가능.
   먼지4~5장은 시작1회, 필요한 핵심사본이 없을 때 층당빙정최대1장,
   생존하는 실제 턴종료 회복400을 적용한다. 추가 피해반감·카드봉인·회복차단문법은 넣지 마라.
3. Deep은 1페이즈의 실제 룬 기여도로 정한 서로 다른 공격형 룬을 최대2회 봉인한다.
   자원형 제외, 현재/과거/현재진행/현재완료/will미래 중 덱으로 가능한 주절과제로 해제한다.
   해제된 같은 공격부터 룬을 복구하고 해방×1.25를 1회 적용한다.
   다음 룬은 다음턴부터 봉인. 매턴 WORD최대2장만 별도 봉인한다.
   무료 정답 재료·빙정·HP1·회복은 없다.
4. Universal은 모든 방해를 정리한 순수화력전이다. 각페이즈는 정상6턴과
   손패/교환/전투당자원을 새로 시작하며, 페이즈 사이 카드보상/상점은 없다.
   47 기존보상과48직전마지막상점은 각각1회. 50격파는 실제원정클리어다.
5. 완주한원정의 최고최종위력과 그 실제문장을 함께 보존해 플레이어별Top20에 표시한다.
   숫자만 저장하거나 최근12공격에서 사후 복원하지 마라.
   공용인프라는 미지정이다. 로컬실기록과공용어댑터를 구분하고
   공용미연결을공용랭킹완료로 보고하지 마라. 임의 외부계정·비용·배포를 만들지 마라.

HP/목표/봉인2회는 사용자 확정이다. 회복400·해방1.25와 문서의 세부정의는
구현 초깃값이다. 실패seed에 맞추어 HP·룬·보상·기존난이도를 임의조정하지 마라.

문법판정과 실제상태를 바꾸는 규칙은 집중 검증하라.
동봉20개핵심묶음을 기존자동화와 작은추가검사로 확인하고,
최종코드에서 npm test, npm run validate:data, npm run build를 실행하라.

태블릿가로는 새문구/조작의잘림만 간단확인하라.
