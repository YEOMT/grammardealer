# 0.11 집중 검증 및 빠른 인계 기준

## 원칙

상태·카드·정산·클리어 자격은 확인한다. 디자인의 모든 픽셀과 브라우저 조합을 새로 검사하지 않는다. 아래 **20개 묶음**은 완료 기준이지 20개의 독립 브라우저 스크립트나 수백 개 캡처 요구가 아니다. 같은 근거로 여러 항목을 충족할 수 있다.

정적 확인, 순수 규칙 단위검사, Controller 통합검사, 실제 브라우저, 자연 원정, 실기기는 구분한다. 실행하지 않은 것은 NOT RUN. 데이터 파일의 기대값을 코드가 그대로 반환하도록 만든 테스트는 실제 엔진 검증이 아니다.

## 문법 검증 예시

문장은 테스트 구조를 설명하는 후보다. **등록 카드 사본과 엔진 지원을 실제로 확인**하고, 미등록 어휘는 같은 구조의 등록 어휘로 바꾼 사실을 기록한다. 예문만 보고 PASS로 선언하지 않는다.

| 종류 | 후보 | 기대 |
|---|---|---|
| SV | I work. | 주절1형식 |
| SVC | I am happy. | 주절2형식 |
| SVO | I read books. | 주절3형식 |
| SVOO | I give you books. | 주절4형식 |
| SVOC | I make you happy. | 주절5형식 |
| 4형식 음성 | I give books to you. | 4형식 목표는 실패 |
| 수동 | I am helped by you. | 수동 목표 성공 |
| 수동 음성 | I am happy. | 수동 목표 실패 |
| 부정사 | I want to read books. | to부정사 성공 |
| 부정사 음성 | I give books to you. | 전치사to는 실패 |
| 가주어 | It is good to read books. | 가주어/진주어 성공 |
| 관계절 | I like the book that you read. | 수식 관계절 성공 |

| 가정법 | If I had time, I would read books. | 가정법 성공, 실제과거 목표로 오인정 금지 |

## 실제 실행 범위

- 현재 저장소가 요구하는 `npm test`, `npm run validate:data`, `npm run build`를 최종 변경본에서 한 번 실행한다.
- 신규 순수규칙/Controller 검사를 기존 test suite에 넣고, 관련 브라우저 경로 1개를 추가하거나 재사용한다.
- 실패를 고친 뒤 영향 있는 검사만 다시 실행한다. 단순한 보고서·문구 수정 때문에 모든 긴 E2E를 다시 돌리지 않는다.
- 자동 자연원정이 앞 지역에서 패배하면 사람 승률이나 최종보스 불가능의 근거로 쓰지 않는다. 그 자동정책을 완벽하게 고치는 일을 이번 필수범위로 확대하지 않는다.
- 전용 아트·실기기·공용 서버가 없다면 각각 NOT RUN/미제공/미연결. 게임플레이 기능 완료 여부와 분리한다.
- 추천 증거: PC 최종전 상태와 완료/랭킹 화면 등 2~3장, 짧은 테스트/빌드 결과. 대량 영상·캡처 필수 아님.
