# Syntax Atlas 0.11 — 50전투 최종 보스 인계

## 사용법
Codex에 이 ZIP 하나를 첨부하고 `Syntax_Atlas_0.11_START_PROMPT.txt` 내용을 붙여 넣는다.
이전 UI 패치를 다시 적용할 필요는 없다. 최신 실제 소스를 기준으로 개발한다.

## 읽는 순서
1. `01_START_PROMPT_KO.md`
2. `Syntax_Atlas_0.11_FinalBoss_Spec.md` — 최종 합의와 구현 초깃값, 전투·상태·호환
3. `02_Clear_Leaderboard.md` — 최고문장·Top20·로컬/공용 구분
4. `03_Focused_Verification.md` — 20개 핵심검사 묶음과 간단한 인계
5. JSON 3개 — 정책·산술 기대값·경계 사례

문서 내용은 구현 지시다. 게임 소스나 테스트 통과 보고가 포함된 패키지는 아니다.
회복400, 해방1.25 등은 초기안이고 실제 난이도 검증이 끝난 값이 아니다.
게임/원정50완성, 로컬기록, 공용랭킹운영, 전용아트는 완료범위를 구분해야 한다.

## 검증 철학
방어막/봉인/카드/저장/클리어/기록은 집중 확인한다.
현재 UI는 보존하고 불필요한 전체기기·50전투 자동완주·대량 캡처를 요구하지 않는다.
디자인과 실제 난이도는 사용자 플레이 피드백으로 후속 조정한다.

## 패키지 내부 확인
`MANIFEST_SHA256.json`은 파일 무결성 목록이다.
`PACKAGE_CHECK.json`은 이 명세의 JSON/산술/파일 일관성 확인 결과일 뿐,
실제 게임 엔진·빌드·브라우저 검증 결과가 아니다.
