# 0.5.1 핵심 피드백 검토

`presentation.js`는 확정 AttackResolution을 읽으며 상태는 RunController만 커밋한다. 장식용 animate와 핵심 animateCore를 구분한다. 공격체는 원래 문장 조립체의 상호작용 불가 복제이며 화면 좌표의 오버레이에서 이동한다. 실제 카드/영수증/피해를 복제하지 않는다. 종료·취소 시 복제·WAAPI·타이머·연결선·잠금을 정리한다.

| 조건 | 핵심 반응 | 장식 |
|---|---|---|
| 정상 + 효과 감소 OFF | 돌진, HP, 반동, 확정 위력/룬 이름 | 궤적/링/룬 비행 |
| 정상 + 효과 감소 ON | 같은 핵심 돌진/반동/HP/역할/룬 슬롯 | 장식 생략 |
| OS reduce + OFF/ON | 비이동 테두리/밝기와 HP/결과 | 큰 이동/화면 흔들림 없음 |
| WAAPI 없음/예외 | 제한된 테두리/밝기 대체, 정리 | 성공으로 위장한 무시가 아닌 fallback 진단 기록 |
| 음소거/음량0 | 화면 피드백 유지 | 기존 audio 설정이 출력 제어 |

실제 초과분>0인 격파만 오버킬이다. P=post-boss finalPower, H=남은 HP, B=일반 적 최대 HP다. P/H≥2.5 및 P/B≥1이면 MASSIVE(150ms/22px/8px), P/H≥1.5 및 P/B≥0.5이면 LARGE(120ms/14px/5px), 나머지는 SMALL(90ms/8px/3px). 순서대로 hit-stop/적 반동/화면 반동이며 settle≤450ms, 화면 반동≤180ms다. 정확한 격파는 기존 일반 정책, 실제 피해0은 BLOCKED다. HP1의 작은 마무리를 최대 오버킬로 부풀리지 않는다.

검사 층위를 구분한다.

- 20개 fixture 수치는 분류·경계·불변성의 합성 검사다.
- `core-polish-browser.mjs`는 지정된 확정 resolution과 실제 DOM/CSS/네이티브 시계로 rAF마다 공격체 위치·가시성·반동·HP를 측정한다. 실제 원정 공격으로 주장하지 않는다. 효과 감소/OS reduce 네 조합, 속도2, WAAPI 없음/예외, 최대16조합/14손패/4룬을 포함한다.
- 기존 VFX 검사는 실제 문법·점수로 만든 resolution에서 룬 비행과 숨김·중단·렌더 오류를 확인한다. 지정 렌더 상태다.
- 실제 앱 튜토리얼 gate 스킵은 두 번의 실제 카드 공격 뒤 대기/취소/오래된 콜백을 검사한다. production 원정은 별도 E2E다.

원본 영상과 매 프레임 측정은 로컬 `.local-validation/v051/`에, 선별 캡처·짧은 영상은 [검증 폴더](validation/v0.5.1/)에 보관한다. 사람의 스피커 청취와 타격감 취향 평가, 실 iPad Safari는 **NOT RUN**이다. 자동 audio 호출 검사는 청취 결과가 아니다.
