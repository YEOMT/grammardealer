# 0.5.1 교육·형태 UI 검토

검토 대상은 표시 데이터 `src/data/grammarDisplay.js`, 렌더러 `src/ui/overlays.js`, 표시 전용 `src/ui/formView.js`다. production에서 첨부 JSON을 가져오거나 정답 문자열을 판정하지 않는다. JSON과의 동등성 검사는 설명·순서의 계약 검사이며 게임 문법 검증을 대체하지 않는다.

| 항목 | 표시 결정 | 기존 의미·판정 보존 근거 |
|---|---|---|
| 1~5형식 | SV/SVC/SVO/SVOO/SVOC 순서, 제목 옆 괄호 | parser와 comboEligibility 분리 유지; 미해금 정상문장도 제출 |
| 형용사·부사·전치사구 | 각각 1문장 설명 | 사용 범위는 기존 분석기; 새 강의·예문 패널 없음 |
| 과거·진행·미래 | 형태와 기준 시점의 짧은 설명 | 기존 동사구와 시간 증거 그대로 |
| 완료 | 기준 시점까지의 일/남은 영향 + 현재완료의 연결 | 사용자 취지인 과거와 현재의 연결을 보존하되 모든 완료를 현재로 한정하지 않는 명세 보정 |
| 절 | 주어와 동사를 중심으로 이루어진 덩어리, 접속사로 연결 가능 | 절 하나도 문장이 될 수 있어 ‘문장과 별개’라는 오해를 피하는 명세 보정 |
| to부정사·동명사·현재분사 | 명사 역할/수식/목적을 간결하게 구별 | 역할 선택 버튼 없음. 전체 구조 제출 뒤 판정 |
| 영어 기록/피드백 | 흰색 볼드 영어, 적색 및 ‘피드백’ 표식 | 당시 위력·분석 상세는 접어서 계속 접근 가능; 번역 없음 |
| 사전 | 뜻·품사·형태·희귀도·보유·연마 유지 | 가산성 BOTH와 to/for, enjoy/finish -ing 등의 짧은 주의 유지 |
| her/you/it | 같은 lexeme·surface만 단일 버튼 | 모든 기존 Form ID를 별칭으로 보관, 과거 선택도 current 표시 |
| I/me/my, he/him/his | 다른 철자는 별도 | lexeme 간 병합 없음 |
| read/had 등 동사 | 시제/과거분사 버튼 유지 | 대명사 외 그룹화 없음. 과거분사(p.p.) 표기만 통일 |
| -ing | 하나의 기존 형태 | 진행/분사/동명사 전용 형태·카드 추가 없음 |

`v051-polish.test.js`에서 모든 대명사 별칭의 보존과 `I like her` / `I like her book`의 실제 파서 판정을 확인한다. 과거/준동사/절 회귀는 기존 테스트 전체를 실행한다. UI 검사는 1366×768, 1280×800, 1024×768과 CSS zoom 125%에서 17항목·제목/본문 크기·가로 넘침·열기/검색 전후 원정/프로필 불변을 확인한다. CSS zoom은 브라우저 툴바 확대나 실 iPad를 대신하는 증거가 아니다.

교사 최종 검수, 학습자 이해도 및 실기기 읽기 평가는 **NOT RUN**이다. 위 표는 코드·명세 대조 검토다. 실제 엔진별 결과는 [테스트 보고서](TEST_REPORT_0.5.1.md)를 따른다.
