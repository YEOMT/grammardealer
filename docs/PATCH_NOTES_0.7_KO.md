# Syntax Atlas 0.7.0 — 잿불 동굴

기준은 작업 시작 때 fetch한 `origin/main`의 `e2a878640dc88bce12e62ad6041a59867e09ef92`입니다. 새 원정만 32전투로 확장하며 이전 저장은 당시 정책과 완료 경계를 유지합니다.

## 플레이 변경

- 설원 보스 보상과 지역 완료 뒤 잿불 동굴에 입장합니다. 불씨 도롱뇽 → 현무암 거북 → 화로 대장장이 정령 → 메아리 박쥐 → 잠든 잿불룡 순서입니다. 새 상점이나 영구 무료 카드는 없습니다.
- 일반 전투에는 검은 먼지 2장, 보스에는 5장이 섞입니다. 먼지는 전투 한정 OBSTACLE이며 교환·재셔플·보급·재활용이 가능하지만 문장 배치·형태 선택·사용·연마는 불가능합니다. WORD/품사 탐색에서는 제외됩니다. 첫 손패는 먼지 최대 1장이고 실제 WORD 문장 증거를 보존합니다.
- 검댕 비늘은 피해를 75% 줄입니다. 양수 위력 공격에서 실제 동사 -ing/p.p. 카드를 정상적으로 사용하면 그 공격부터 영구 해제됩니다. 진행·완료·동명사도 가능합니다. 단순 과거형 made/read, 독립 형용사 interesting/tired의 철자는 해제 근거가 아닙니다. HP 1 잠금은 없습니다.
- 기존 동사·Form ID로 명사 앞뒤 분사 수식, 수동태, 동사별 목적격보어를 지원합니다. 수동태는 be + p.p.와 해당 Sense의 수동 허용 정보를 함께 확인하고 표면 문형과 원래 문형을 따로 기록합니다.
- 정상 수동태의 해금된 콤보는 ×1.8, 새 구조를 사용한 잿불 동굴 지역 보너스는 ×1.25입니다. 각각 공격당 한 번이며 명사 수식·동명사·목적격보어를 중복 가산하지 않습니다. 진행/완료/동명사만으로는 새 지역 배수를 받지 않습니다.

## 보존 범위

28장 시작 덱, 기본 전투 자원, 기존 6지역 HP, 4룬 슬롯, 세 상점, 운영 7종/+1과 재사용 정책, 0.6.1 운석 배수, AP-to gap, 동사구 내부 부사, 실습/스킵, 개인 기록과 저장 정책을 유지합니다. 새 WORD·운영 정의·룬·의존성을 추가하지 않습니다. 저장소·내부 패키지/DB·`/grammardealer/`도 유지합니다.

0.6.1 원정은 계속 `STAGE6_END`/27전투에서 끝납니다. 새 0.7 원정은 `STAGE7_END`/32전투에서 끝나며 storyClearCount를 올리지 않습니다.

## 수치의 성격과 검증

새 적 HP 960/1040/1120/1200/1440과 새 배수는 이번 명세의 구현 초깃값입니다. 자동 정책 완주를 학생 난이도나 사람 승률 근거로 삼지 않습니다. 실제 실행 상태·실패 이력·미검증 항목은 [검증 보고서](TEST_REPORT_0.7.md), [인수표](ACCEPTANCE_0.7.md)를 참조하십시오.

검토 순서: 기존 저장 불러오기 → 새 원정 실습/스킵 → 설원까지 기존 진행 → 잿불 동굴 소개 → 먼지 교환/탐색 → 분사·수동·목적격보어 → 진행/완료를 통한 비늘 해제 → 마지막 보상 → 완료 저장 복원.
