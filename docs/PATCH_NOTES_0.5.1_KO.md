# Syntax Atlas 0.5.1 · Core Polish

새 콘텐츠 없이 기존 22전투의 표시와 조작을 정돈한다. 기준은 작업 시작 최신 origin/main `2c03b2492b21f2bca27f10718e35bc4e291861bb`이며, 시작 checkout은 깨끗했다. 작업 브랜치는 `codex/v0.5.1-core-polish`이다.

- 효과 감소는 장식만 줄인다. 조립 문장의 돌진·HP 변화·적 반동·확정 위력은 남는다. OS 동작 줄이기는 큰 이동 대신 테두리/밝기 반응을 쓴다. WAAPI가 없거나 실패해도 제한된 대체 피드백과 정리를 수행한다.
- 오버킬은 확정된 실제 초과 피해를 표시한다. 적 최대 HP와 남은 HP를 함께 고려하고 반동·hit-stop을 제한한다. 피해·재화·보상을 추가 계산하지 않는다. 0피해와 골렘 중간 부위 파괴를 전체 격파로 표시하지 않는다.
- 튜토리얼 시작/건너뛰기를 제공한다. 스킵은 보관한 정상 28장과 RNG를 복구해 일반 1-1을 시작한다. 완료·승리·보상을 주지 않으며 다음 원정에 재강제하지 않는다. 설정에서 독립 튜토리얼을 다시 볼 수 있다.
- 도감의 17개 문법은 1~5형식을 먼저 표시하고 같은 제목 줄에 형태를 붙인다. 설명은 검토 가능한 고정 데이터이며 길게 반복한 공통 강의를 제거했다. 영어 기록·역할·실제 위력은 보존한다.
- 대명사의 같은 철자는 한 형태 버튼으로 묶는다. 저장된 Form ID와 파서 후보는 유지한다. 동사의 같은 철자 시제는 합치지 않으며 단일 -ing도 유지한다.
- **새 0.5.1 원정만** Stage 4 HP 520/570/620/680/760, Stage 5 HP 620/670/720/780/960을 쓴다. 명세의 난이도 초깃값이며 학생 난이도 검수 완료를 뜻하지 않는다. Stage 1~3 및 구버전 저장의 HP는 그대로다.
- 로컬 패키징 안내는 Syntax Atlas와 자동 버전을 사용한다. ZIP을 다시 열어 산출물 해시를 검증하며 런타임·비밀정보·로컬 검증 폴더는 넣지 않는다.

문법·공격 점수·룬 배수·시작 덱·전투 자원·상점·보상·운영·봉인은 0.5 정책을 명시적으로 재사용한다. 의존성은 그대로다. main 병합·공개 배포와 브랜치 전달은 별개다.
