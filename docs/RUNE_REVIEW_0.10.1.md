# 0.10.1 룬·획득·교육 검토

HP 및 곱셈 값은 확정값이다. 화석/석영의 +30/+50/+70과 280ms·18ms stagger·90ms 상한·입자/글로우/스케일은 명세의 검증 초깃값이다. 실제 과거진행의 화석+석영, 현재완료진행의 석영+백금, 가정절 연결의 라피스+미스릴은 명세가 요구한 복합용법 세부안이다. 기본 문법의 중복 배율 억제를 해제하지 않는다.

`eligibleGrammarAnalysis`는 오류·해금을 먼저 적용한다. `buildRuneEvidence`는 이 view에서 노드와 실제 사본 ID를 읽는다. `scoreableAnalysis`의 숫자 배율 대체 전 근거와 이후 점수 계산을 분리하므로 현재완료진행/가정법의 기본 하위 배율을 되살리지 않는다. 신규 룬은 룬별 공격당 한 번, 장착 순서대로 가산/매곱셈 버림을 적용한다. 입력 문장 정답표나 fixture를 production에서 읽지 않는다.

일반/고급은 Stage1부터 전체 후보이며 보유 룬의 최대 레벨만 제외한다. 일반전·1-2 소개·Stage2 상점은 다이아몬드 포함 희귀 0이다. Stage1부터 지역 보스 보상, Stage4/6/8/10 상점은 희귀가 가능하다. 등급 필터 뒤 194:97:9 또는 194:97로 정규화하며 등급 내 균등 추첨을 유지한다. 확정 희귀·천장·덱 적합성 가중치를 추가하지 않는다. 룬 획득은 문법 해금이 아니다.

제품 설명은 `polish0101Runes`의 고정 조건과 UI의 세 레벨 값으로 만든다. 도감/상점/보상에 획득 가능과 발동 해금 상태를 구분하고, 제출 전 점수/정답 예측은 제공하지 않는다. 새 번역·AI API·문법 콘텐츠는 없다.

문장 fixture 44개 중 G030의 원문 `I know the boy who helped me.`는 현재 카드 DB에 boy가 없으므로 목표 검사 **NOT RUN**이다. 미지원 감지와 등록된 teacher로 같은 관계절 구조를 검사한 결과는 별도 기록하며 원문 PASS로 바꾸지 않는다. 최종 실행 수와 로그는 TEST_REPORT_0.10.1.md를 따른다.
