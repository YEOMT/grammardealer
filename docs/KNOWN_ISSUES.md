# 알려진 범위와 검증 한계 — 0.2

실제 명령·종료 코드·새 검사 결과는 [TEST_REPORT_0.2](TEST_REPORT_0.2.md)를 기준으로 한다. 이전 버전 실행 결과는 history 및 baseline 보고서에 보존한다.

- **실제 iPad Safari/Android, Firefox/WebKit: NOT RUN.** 네 가로 해상도와 Chromium 터치 에뮬레이션은 실제 기기 검사를 대신하지 않는다. 모바일 세로 전용 설계는 이번 범위 밖이다.
- Stage 2와 상점은 구현했지만 전체 48전투 스토리·Stage 3 이후·다른 캐릭터·난이도 2 이상은 미구현이다. STAGE2_END는 전체 스토리 클리어가 아니다.
- 자동 플레이는 현재 손패만 사용하는 유한 탐색이다. 첫 160개 비교 실행에서 LEARNING 40/80 완주, SV_ONLY 0/80 완주, 기술 오류 0이었다. 패배 시드도 보고서에 포함한다. 이는 사람의 승률·시드의 절대 불가능성·2560점 빌드의 실제 달성을 뜻하지 않는다. Stage 2 HP 220/300/380/640과 상점 가격은 명세 시작값을 유지했다.
- 매 턴 카드/룬/재화를 자동 복구하지 않는다. 입장 시 0~2장 준비 후 플레이어가 재료를 제거하면 경로가 없어질 수 있다. 이 경우 표시된 경고와 정상 보상/상점 선택만 제공한다.
- 의미 참고는 검증한 현재형 작은 템플릿에 한정한다. 긴 수식·일반 PP·다의적 play·복구된 문법 오류 등은 성분별 뜻으로 남는다. 기존 소유격 뜻 참고/COMPLETE_HINT 경계는 전면 수정하지 않았다. 의미 자연스러움은 문법 정오나 점수에 영향을 주지 않는다.
- 기존 공격 기록의 과거 languageVersion 문자열은 다시 쓰지 않는다. 새 공격은 원정의 languageVersion을 기록한다. 전투 중 기존 턴 보너스 사전 안내의 별도 개선도 이번 범위 밖이다.
- 구버전 원정은 당시 Stage 1과 후보풀로 끝난다. 같은 프로필로 새 0.2 원정을 시작해야 항구를 플레이할 수 있다. 공개 보상·상점과 저장된 RNG는 로드 시 재추첨하지 않는다.
- 첫 리소스 로드 이후 오프라인 진행·저장은 검사하지만, 오프라인 새 로드/PWA/브라우저 간 저장 이동은 제공하지 않는다. IndexedDB는 origin별로 구분된다.
- 실제 디스크/스토리지 quota 소진과 OS 수준 저장 고장: NOT RUN. 기존 transaction abort 검사 및 변조된 저장/거래 입력 거부 검사와 구분한다.
- 이번 작업에서 main 병합·auto-merge·Pages 설정 변경·공개 배포는 수행하지 않는다. Production 로컬 하위경로 검사와 실제 공개 사이트 갱신을 구분한다.
