# 알려진 문제·검증 한계 — 0.1.1

최종 자동/Chromium 검증에서 해결되지 않은 치명적 동작 오류는 발견되지 않았다. 아래 경계는 계속 남아 있다.

- **실제 iPad Safari/Firefox/WebKit/실제 Android는 NOT RUN.** 1024×768·1180×820 및 Chromium touch emulation 결과만 있다. OS 키보드/메모리 압박/백그라운드 복귀는 실제 기기 후속 QA가 필요하다.
- 원격 GitHub clone/push/Actions 실행/Pages 설정·배포·공개 URL 접속 확인은 NOT RUN. workflow와 소스 구조는 준비하고 정적 검증했다. 실제 main의 기존 파일/충돌도 아직 확인하지 않았다.
- 저장 quota를 실제로 소진하거나 물리 디스크 오류를 발생시키는 검사는 NOT RUN. native IndexedDB transaction abort 주입 후 기존 슬롯 보존/복구는 이번 실행에서 PASS다.
- 80개 합법 자동 플레이 중 77회 완주. SV_ONLY 제한 정책은 16회 중 13회 완주했고 3회 패배했다. STANDARD/SHORT/ADVERB/POLISHED는 각16회 완주했다. 이는 제한된 QA 정책 결과이며 사람 승률·모든 seed의 승리 보장은 아니다. HP를 낮추거나 카드를 추가하지 않았다.
- 한글 뜻 참고는 작은 검증 템플릿만 사용한다. PP/긴 수식/일부 어휘/play 다의성은 성분별 뜻으로 남는다. 자연스러움 판정/전체 번역기는 아니다. 과거 기록의 의미 정보가 없으면 복원했다고 주장하지 않는다.
- 첫 공격 전에 안내를 따르지 않고 다른 합법 문장을 제출해도 진행할 수 있다. 미수행 단계는 완료로 꾸미지 않고 ALTERNATIVE_PLAY 건너뛰기로 기록한다.
- 확장 손패 14장은 가로 스크롤을 사용한다. 작은 가로 화면의 긴 룬 설명은 패널 내부 스크롤로 확인한다. 공격 버튼과 현재 자원은 화면에서 접근 가능하다. 세로 휴대폰 전용 배치는 범위 밖이다.
- 첫 로드 후 네트워크가 끊겨도 플레이/저장은 가능하다. 오프라인 새 로드/PWA/브라우저 간 저장 이동은 제공하지 않는다. origin이 달라지면 별도 IndexedDB를 사용한다.
- Stage2·전체 스토리·고급 문법·새 캐릭터·서버/랭킹은 OUT OF SCOPE. 현재 고급 문법은 안전하게 UNSUPPORTED이며 해금 metadata가 곧 구현을 뜻하지 않는다.
