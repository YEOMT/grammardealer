# Syntax Atlas 0.8.1

현재37전투와 수치를 유지하며 문법 판정과 카드 정보를 정돈했다.

- 인칭대명사에 생략 목적격 관계절을 붙이거나 비정형 절을 등록 명사 선행사로 취급하던 오인정 경로를 교정했다. 정상 관계절·동명사와 기존306개 결과를 보존했다.
- help는 기존 고급 동사 카드 한 장에 불가산명사 ‘도움’을 연결한다. 명사 용법은 기본형help이며 제출 후 구조로 판정한다. 새 시작 덱·상점에서 제외하고 고급 전투 보상으로 얻는다. 기존 보유 카드·사본·연마는 유지한다.
- 운영·빙정·방해의 긴 설명은 클릭/터치 상세로 옮겼다. 고급은 은빛, 희귀는 금빛 세공, 연마는 품사색 배지와+3 안쪽 장식을 사용한다.
- Stage1~8 고정 학습 안내와 실제 지역 보너스를 구분한다. 입장 지급 안내는 한 번의 알림이며 보스 설명은 특징/행동/처치 조건으로 줄였다.
- 기존 정산 영수증은 저장 당시 규칙으로 읽고 새 제출은 교정된 규칙으로 판정한다. 이전 피해/보상을 다시 정산하지 않는다.

## 검토 플레이 순서

1. 새 원정에서 실습을 완료하거나 건너뛰고, 카드 조립·형태·교환·준비·공격 흐름을 확인한다.
2. 고급 전투 보상에서help를 획득한 뒤 `I help you.`와 `I need more help.`를 제출하고 공격 기록의 동사/명사 표시를 확인한다. 수동 품사 모드는 없다.
3. 운영·빙정·검은 먼지의 상세를 열고 닫아 상태가 바뀌지 않는지, 연마+1~+3과 희귀도 표시가 구분되는지 확인한다.
4. Stage3/5 입장 알림, 사막의 to부정사 상세, 사슴의 짧은 설명과 자세한 예외를 확인한다.
5. Stage8에서 정상 주격·목적격·관계부사와 같은 한 문장 이중 인장을 사용하고, 완료 상태를 저장·불러온다.
6. 기존 저장의 보유help·연마·상품·진행을 확인한다. 신고된 비정상 관계절을 다시 제출하면 기존 실패 정산 정책에 따라 카드/턴을 소비하고0피해다.
