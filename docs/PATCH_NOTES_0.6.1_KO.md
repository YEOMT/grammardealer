# Syntax Atlas 0.6.1 변경 내역

0.6.1 새 원정에 문법·운영 카드 정책을 추가한다. 기존 원정은 저장된 버전의 언어, 운석, 상품, 입장 지급, RNG, 완료 경계를 유지한다.

- 영구 운영 카드 7종의 연마 상한은 +1이다. WORD의 +3 상한은 유지한다. 보급·직접 탐색 +1은 획득 수를 유지하고 효과 해결 **뒤** 버린 더미로 이동한다. 실제로 다시 뽑으면 같은 사본을 다시 사용할 수 있다.
- 명사·동사·형용사 탐색은 DRAW 현재 순서에서 2장(+1은 3장), 연결어 탐색은 1장(+1은 2장)을 가져온다. 재활용은 DISCARD에서 무작위 비복원으로 1장(+1은 2장)을 가져온다. 신규 5종은 연마해도 전투당 한 번이다.
- 세 상점에 운영 상품 한 칸을 보장한다. Stage 4에서 직접 연결어를 영구 보유하지 않았을 때 and/but/because 중 한 장을 무료 선택한다. think/that 부족분 지급은 유지한다.
- 거울뿔 사슴 첫 손패에 전투 한정 빙정 탐색 한 장을 추가한다. 연마·공격·결정 파괴에 사용할 수 없고, 사용 후 사용 완료 영역에 있다가 전투 종료 때 제거된다.
- `A room was too hard to show.`의 AP에 연결된 부정사 목적어 자리를 실제 주어 노드에 연결한다. `is often giving`, `has often given` 등의 부사를 동사 카드와 구분한다. 복구 가능한 형태 오류는 식별된 본동사 문형을 없애지 않는다.
- 새 운석 배율은 Lv1 1.8/2.4, Lv2 2.2/2.8, Lv3 2.6/3.2이다. 기존 0.6 이하 원정의 배율과 과거 점수 기록은 다시 계산하지 않는다.
- 빙정 카드의 body/footer 전체에 옅은 푸른 바탕을 적용한다. 지역별 어두운 그라데이션을 소개·상점·전투·완료 화면에 연결하고 기존 사막 톤을 보존한다.

기본 28장, 6턴, 교환/손패/문장 자원, 27전투와 HP, 다른 룬·점수 계수, 기존 보스 및 실습 규칙은 유지한다. 정확한 실행 결과와 미검증 범위는 [검증 보고서](TEST_REPORT_0.6.1.md)를 따른다.
