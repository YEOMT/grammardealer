# Syntax Atlas 0.6.0 · 거울의 설원

새 원정은 거울의 설원 다섯 전투를 포함한 27전투다. 0.5.1 이하 저장은 당시 언어·수치·콘텐츠 종료 지점을 사용한다. 시작 덱 28장, 전투 자원, Stage 1–5 HP, 기존 룬과 두 상점, 운영 카드, 실습 완료/스킵 정책은 유지한다.

- 비교급·최상급·as ~ as·too/enough를 구성 요소로 분석한다. 형태를 선택할 수 있는 기존 형용사·부사 카드에 검수된 형태를 추가했다. 새 문법은 해금 전에도 정답이며 콤보는 해당 원정의 Stage 5 완료 후 열린다.
- 설원 입구의 세 번째 상점은 룬 2개·카드 3개와 연마·제거 각 1회를 제공한다. 상품과 가격은 고정되며 제거 누적 가격은 이전 방문에서 이어진다.
- 빙정은 전투에 한정된 실제 WORD 사본이다. 조합·교환·보급·탐색이 가능하고, 공격 제출 시 파괴된다. 전투가 끝나면 모든 임시 사본을 제거한다. 영구 덱과 시작 덱을 늘리지 않는다.
- 거울뿔 사슴은 빙결핵 5개를 가진다. 양수 위력의 성립한 공격에서 실제 결정 대상 빙정을 소비하면 사본 수만큼 파괴한다. 비교 문법을 강제하지 않는다. 결정이 남으면 HP 1을 보존하고, 마지막 결정을 깨는 공격부터 처치할 수 있다.
- 도감에 네 비교·정도 항목을 추가했다. 빙정의 전투 한정 표기, 비교 형태 메뉴, 보스 결정 수와 HP 잠금 이유를 표시한다.

Stage 6 HP 760/830/900/970/1280과 신규 콤보 수치는 명세의 구현 초깃값이다. 1.8/1.9/1.8/1.5, 배수 비교 +20, 설원 지역 ×1.25를 그대로 사용한다. 자동 플레이 결과에 맞춰 HP나 룬 배율을 낮추지 않았다.

실행 결과와 한계는 [검증 보고서](TEST_REPORT_0.6.md), 개별 요구사항은 [173개 인수표](ACCEPTANCE_0.6.md)를 따른다. 명령 자동 원정, 지정 상태, 실제 production UI를 서로 구분한다. PR은 검토용이며 main 병합이나 공개 배포를 수행하지 않는다.
