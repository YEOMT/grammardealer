# 0.10 언어·교육 검토

이번 실행의 근거는 `tests/v010-corridor-grammar.test.js`, `tests/v010-corridor-state.test.js`, `tests/v010-corridor-edges.test.js`다. JSON은 기대자료이며 production은 이를 import하지 않는다. 특정 문장 문자열을 정답표로 사용하지 않는다.

| 구문 | 실제 구조 근거 | 채점 처리 | 확인 |
|---|---|---|---|
| 현실 조건절 | if 부사절의 현재 유한 VP + 결과절 will/can 원형 VP | ×1.6, 같은 if 연결 제외; 실제 will 미래는 보존 | G001~ 및 독립 근거 검사 |
| 가정법 과거 | if 과거형/국소 irrealis were/could + 결과절 would/could 원형 | ×1.8, 같은 가정형의 실제 과거·미래 중복 없음 | 실제 선택형, 일반 I were 오류 경계 |
| 과거완료 | 유한 had + 실제 p.p. 연결 | ×1.4, 같은 VP의 과거·완료 대체 | lexical had와 구분; 다른 came 과거 보존 |
| 가정법 과거완료 | 서로 다른 VP의 had+p.p.와 would/could+have+p.p. | ×2.0, 같은 쌍의 하위 과거완료·완료·if연결 대체 | 두 have 사본 및 잘못된 came/has/원형 부정 사례 |
| 현재완료진행 | 유한 have/has + been + ING | ×1.8, 같은 VP 완료·진행 대체 | 별개 절의 has helped 완료·and 연결 보존 |

원시 clause/VP/card/node ID와 corridorStructures는 보존한다. 채점 필터는 suppressedScoreEvidence 영수증을 남긴다. 문두 if절이 있어도 결과절을 주절로 읽는다. 과거형의 형태와 가정 mood를 분리하고, 동사 lemma를 시제 판정 근거로 삼지 않는다. 해금 전 문법 성립은 그대로이며 새 배율·지역 자격만 잠긴다. 완료진행은 기존 완료·진행 두 팩 동시 해금에서 열린다. 회랑 팩은 프로필 상속이 아닌 해당 원정 실제 입장으로 연다.

| 카드/교육 문구 | 검토 내용 |
|---|---|
| will/would | 한 사본의 두 선택형. would만으로 미래·가정법 보너스가 생기지 않는다는 설명 |
| can/could | 고급 WORD, 시작덱 제외. 단독 could의 능력·가능성과 조건쌍의 가정을 구분. 일반 과거/가정 점수를 자동 부여하지 않음 |
| p.p. | 도감의 과거완료·가정법 과거완료 설명에 “과거분사” 명시 |
| 기록 | 실제 선택한 surface와 동사구 역할을 사후 표시. 편집 중 예상 문형·점수·차단 여부는 노출하지 않음 |
| 일반전 안내 | 현실 조건절 → 가정법 과거 → 과거완료 → 가정법 과거완료. 완료진행/I wish 전용 라운드 없음 |
| 보스 | 확정 세 문장 설명, 직전 확정 문형 기억, 공격 중 차단/우회 표시 |

## 기대자료와 실제 실행의 차이

- G011의 `here`, G031의 `young`은 현재 카드 DB에 없다. 실제 카드 snapshot 검사는 각각 등록된 `home`, `happy`로 같은 구성요소 종류를 유지해 실행했다. 원본 JSON은 수정하지 않았다. **원문 그대로의 두 사례는 NOT RUN**이며 등록 어휘 대체 사례의 PASS와 구분한다.
- G045 `I had been reading books.`는 현재완료진행이 아니다. 실제 과거완료 근거는 존재하므로 채점 기대를 PAST_PERFECT로 분리했다. “새 목표 아님”을 모든 완료 근거가 없다는 뜻으로 확장하지 않았다.
- G044 혼합 가정법은 이번 신규 가정법 쌍의 대상이 아니다. 이를 모든 영어에서 비문이라고 단정하지 않고 UNREAL 보너스/예견 우회를 만들지 않는지 검사했다.
- 기존 306개 문법 감사 사례를 0.9와 새 0.10 양쪽에서 재실행했다. 0.10에서 추가되는 corridor 원시 태그를 제외한 기존 status/frame/issues/coverage/tags를 대조했다. 새 우선순위가 `I am knowing that she works.`의 ASPECT_USAGE를 피하던 회귀를 발견하고 기존 동사구 해석 우선순위를 보존해 수정했다. 기대값을 낮추지 않았다.
- 기존 0.6 fingerprint와 0.8.1 37전투 안내 검사도 유지했다. 0.8.1 검사 대상에서 새 9·10지역을 제외한 것은 해당 버전의 기존 범위를 명시한 것이며 37 기대값을 늘리지 않았다. 버전 배지 검사는 새 표시 버전 0.10.0으로 갱신했다.

모든 영어의 자유로운 문맥·모호성을 완전히 판정하는 엔진이라는 주장은 하지 않는다. 혼합/도치 가정법, I wish 전용 구문, might, 미래 완료진행의 새 독립 콤보는 이번 범위가 아니다. 전용 원화/BGM은 미제공이며 임시 CSS·기호를 사용한다.


## 기존 지역 자격 보존

최종 감사에서 현재완료진행의 하위 TIME 배율 대체가 Stage3의 원래 시간 지역 보너스까지 없애는 회귀를 실제 비교로 재현했다. Stage3에서만 해금된 실제 과거완료/현재완료진행 근거를 기존 시간 자격에 연결했다. 별도 문법 배율을 다시 곱하지 않고 지역×1.25는 한 번만 적용한다. Stage10의 완료진행 단독 제외 정책과 다른 지역의 원래 자격은 유지한다. `v010-corridor-edges.test.js`의 실제 문장→점수→지역 비교로 검증한다.
