# Syntax Atlas 0.4.0 변경 내역

새 0.4 원정은 총17전투이며 이음의 하늘섬 완료는 전체 스토리 완료가 아니다. 기존 0.3의12전투·시간 문법·룬·골렘·실습·저장 정책 위에 통합했다.

- 하늘섬: 구름양440 → 갈래바람 정령480 → 매듭뱀520 → 메아리 새560 → 하늘길의 문지기640. 앞4전투의 문법 주제는 권장 경험이며 강제 면역 조건이 아니다.
- 문지기: 시작 보호막 중 비공략 피해50%. 실제 접속사로 정상 절을 연결한 첫 공격부터 전부 적용하고 보호막이 재생하지 않는다. 강한 룬 빌드 원킬을 막는 피해 cap이 없다.
- 언어: and/but/or 구·절, because/when/if 부사절, think/know/say 내용절. that의 지시/관계/내용 역할과 생략 that을 실제 구조로 구분한다. 독립 등위는 첫 절, 종속/내용 결합은 바깥 주절을 점수 기준으로 삼는다.
- 점수 초깃값: 절 연결×1.6, 구 연결+10, 하늘섬 정상 절 연결×1.25, 각각 공격당1회. 기존0.3 문형·시간·수식·룬·단계별내림 유지.
- 보급/탐색: 손패에서 사용, 턴/교환 무료, 실제 사본을 전투 사용완료 영역으로 이동. 보급은2장 드로우, 탐색은 DRAW의 WORD1장 선택. 다음 전투 복귀, 연마 불가, 제거 가능.
- 상점2: 협곡 보상 → 하늘섬 예고 → 없는 재료0~4장 → 2룬/3카드 상점 →13번째 전투. 첫 상점 상품/서비스 기록은 보존하고 유료 제거 증가만 원정에 누적한다.
- 덱/표시:28장 유지, 무작위 SVO슬롯 하나를 have로 고정. 새0.4 be/have/you/I는 고급, base10 유지. 형태 메뉴는 현재/원형·과거 전체폭과 p.p./-ing 두 칸. 이름은 Syntax Atlas/신택스 아틀라스.
- 기록/화면: 제출 뒤 절 연결 다리와 내용절 목적어 영역, 하늘섬 테마·보호막·상점2를 추가했다. 최대16장 조합대/10·14장 손패/4룬 배치를 유지한다. 미완성 제출의 새 절 필드가 undefined여서 개인 기록 저장이 막히던 개발 중 회귀를 null 직렬화로 수정했다.

사용자 확정: 이름·형태 메뉴·have 고정·4카드 고급·운영 효과/비용/복귀·적 순서·50% 및 첫 공략부터 해제·고점 원킬 허용. 명세 설계 초깃값: 하늘섬 HP, 새 연결/지역 배수, 운영 등급/가격/20% 내부 분기, 대표 입장 공급. 밸런스 검증 완료값으로 주장하지 않으며 임의 변경하지 않았다.

구버전은 원래 언어·HP·덱·상품·희귀도·보상·RNG·완료 경계를 유지한다. DB 이름·패키지 내부명·저장소·`/grammardealer/` 경로는 유지한다. 의존성 버전은 변경하지 않았다. 새 서버/번역 API/외부 AI/프레임워크/Stage5/운영 강화는 추가하지 않았다.

첨부 S003의395는 기존 home 부사+5 누락으로 실제401이다. 원본 기대 JSON과 불일치 근거를 모두 보존한다. 실제 테스트와 중간 실패·NOT RUN 범위는 [TEST_REPORT_0.4](TEST_REPORT_0.4.md), 문구/동사 검토는 [교육 검토표](EDUCATION_REVIEW_0.4.md), 운영 거래 검토는 [운영 검토표](OPERATION_CARD_REVIEW_0.4.md)를 따른다.
