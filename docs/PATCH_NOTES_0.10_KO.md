# Syntax Atlas 0.10.0 패치 내역

별의 회랑의 다섯 전투(43~47)와 운명의 직조자를 추가한다. HP는2500/2900/3300/3800/5000. 47전투 보상 뒤 STAGE10_END에서 끝나며 48~50·엔딩·승천은 없다.

will에서would, 새 고급can에서could를 고른다. 실제 물리 사본과 형태로 현실 조건절/가정법 과거/과거완료/가정법 과거완료/현재완료진행을 판정하고 결과절의 기본 문형을 보존한다. 새5배율은1.6/1.8/1.4/2.0/1.8, 지역1.25이며 검증 초깃값이다. 같은 구성의 하위배율만 대체하고 별개 절의 정상 근거는 유지한다.

Stage10 입장에 기존 규칙의5번째 상점을 열고can을 정규 후보에 넣는다. 일반전만 영구 활성 덱에서 부족한if/will/can/have 사본을 빙정으로 지원한다. 제출 시 깨지고 전투 후 정리한다. 10-5 무료지원은 없다.

직조자는 직전 정상 주절1~5형식을 기억한다. 반복문형은 최종피해0, 다른문형은 정상피해다. 구조가 성립한 가정법 과거/과거완료는 예견을 우회하면서 문형도 기억한다. 준비/교환/오류/운영/로드는 기억을 지우지 않는다. 마지막턴 HP0 승리가 우선한다.

새0.10의S7/8/9/10 일반전에만30/35/40/30% 저항을 최종1회 적용하고 저항 전/후·실제HP감소·초과피해를 표시한다. Stage1~6·모든보스·구버전은 대상이 아니다.

구0.9 이하 저장은 원래 정책/상품/RNG/룬/완료 경계로 복원한다. 28장/6턴/16카드와 기존9개보스·help·다이아몬드·희귀도/연마 UI를 유지한다.
