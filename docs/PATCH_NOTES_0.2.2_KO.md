# 0.2.2 — 문장을 제출하고, 단어를 찾아보는 학습 흐름

- 새 원정의 일반 전투에서는 비어 있지 않은 조합을 제출할 수 있습니다. 문장 뼈대가 완성되지 않았어도 사용 카드와 한 턴을 소모하고 피해 0으로 처리합니다. 마지막 행동이면 연출 후 패배합니다. 입력 손상·엔진 오류는 소모하지 않습니다.
- 문법 판정과 콤보 자격을 분리했습니다. 처음 만나는 4형식도 정상 문장으로 공격하며, 초원 클리어로 얻는 `pack.svoo`가 있어야 전용 ×2를 받습니다. 이전 원정에서 해금했다면 새 원정의 초원부터 활성입니다.
- develop의 자동사/타동사와 검수한 동사 연결을 실제 파서에서 처리합니다. 목적격보어, 동사별 to/원형, 제한된 that 관계절과 목적격 관계사 생략은 기본 판정이 가능하고 후반 전용 보너스를 새로 열지는 않습니다.
- 내 덱과 사전은 같은 단어 보기로 연결했습니다. 보유/만난 단어 필터, 보유 장수·연마·등급·주요 한국어 뜻·현재 형태를 확인합니다. DRAW/DISCARD의 실제 더미 조회와 드로우 순서 비공개 정책은 유지합니다.
- 문장 도감은 영어 원문·검증된 역할·실제 발동 문법·당시 위력/피해를 표시합니다. 자동 문장 번역, 성분/단어 번역, 내부 판정 코드를 제거했습니다. 실패/부분 오류와 완전한 문장 대표를 구분하고 고정 예문은 실전 기록과 구분합니다.
- 과거 기록의 원문·집계·점수·해금은 보존합니다. 토큰 증거가 있는 경우 교육용 구조만 재확인하며, 문자열만 남은 불확실한 기록은 모범 예문으로 노출하지 않습니다.

이전 원정은 원래 제출 비용·콤보·HP·카드·보상·상품·RNG·완료 경계를 유지합니다. 새 정책은 새 0.2.2 원정에 적용합니다. IndexedDB와 수동 3슬롯은 그대로이며 새 원정의 빈 조합대 턴 경계에서도 저장할 수 있습니다.

0.2.1 실습의 30/87 두 공격, 초원 HP 77/132/242, 선택 체크, 타격, 0.2의 상점·토파즈·장막·7전투를 유지합니다. 새 카드·룬·지역·서버·번역 API·의존성은 추가하지 않았습니다. 교육 문구는 검토 가능한 고정 초안이며 교사 검수 완료를 뜻하지 않습니다.

검토 순서: 일반 전투에서 잘못된 조합 제출 → 새 프로필/해금 프로필의 4형식 비교 → develop 자동/타동과 be 보어/장소 → 내 덱 사전과 번역 없는 도감 → 실습·첫 룬·상점·항구 보스 완주.
