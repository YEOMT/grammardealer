# Syntax Atlas 0.5.0 — 소원의 사막

기준은 작업 시작 시 fetch한 `origin/main`의 `6d2907eddefafb1a909c6c803259ba26b408f104`(0.4 PR #6 병합)이다. 미커밋 변경이 없는 상태에서 `codex/v0.5-wish-desert-nonfinite-seal`을 만들었다. 과거 ZIP이나 배포 번들로 소스를 대체하지 않았다. 이번 ZIP의 명세·JSON은 요구사항과 독립 기대값이며 실행 결과가 아니다.

## 플레이 변화

- 하늘섬 다음에 별길 낙타 → 금빛 전갈 → 별꽃 선인장 → 신기루 여우 → 소원의 스핑크스가 이어진다. 총 22전투이며 `STAGE5_END`는 현재 제공 범위의 끝이다. 전체 스토리 완료나 새 룬 슬롯 해금으로 처리하지 않는다.
- `to` 부정사, 명사 역할의 동명사, 최소 현재분사 수식, 등록된 기본 5형식을 기존 bounded parser에 연결했다. `want/need/enjoy/finish/like/help/make` 등의 등록된 Sense·Frame을 확인하며 임의 동사에 모든 용법을 허용하지 않는다.
- 각 동사의 기존 `-ing` Form ID 하나를 재사용한다. 메뉴에서 용법을 미리 고르지 않으며 제출 후 전체 구조에서 역할을 판정한다. 도감은 준동사구의 범위·기능·내부 동사를 구분한다.
- 하늘섬 승리 시 부정사·동명사·기본 5형식 팩을 한 번 해금한다. Stage 5 입장 시 실제 보유 WORD를 확인해 없는 `to`, `want/need` 대표 `want`, `like/enjoy/finish` 대표 `enjoy`만 최대 세 장 지급한다. 다시 입장하거나 로드해 재지급하지 않는다.
- 스핑크스는 매 턴 드로우가 끝난 뒤 손패 WORD 한 사본의 조합대 배치를 금지한다. 봉인 카드의 교환과 보급·탐색은 가능하다. 교환 후 같은 사본을 다시 뽑아도 해당 턴의 봉인은 유지한다. 형태·룬·운영·Undo·로드는 추첨 계기가 아니다.
- 손패의 봉인 표시와 교환 체크를 함께 제공한다. 밤 사막 테마와 입장/완료 화면을 추가했고, 최대 카드 배치에서 봉인 표시·운영 카드가 높이를 늘리는 경우에도 공격/교환 버튼이 겹치지 않도록 공간을 조정했다.

## 수치 출처와 보존

사용자 확정 계약은 단일 ING, 제출 후 역할 판정, 사본 단위 턴 봉인과 허용 행동, 기존 덱·자원·점수·룬·두 상점·저장 보존이다. 사막 HP `520/560/600/640/840`, 기본 5형식 `×2.5`, 부정사/동명사 각 `×1.4`, 사막 지역 `×1.25`는 명세의 **구현 초깃값**이며 사람 난이도 검증 완료값이 아니다.

새 효과는 실제 문법 증거와 해금 조건을 만족할 때만 적용한다. 부정사/동명사 계열은 각각 한 번, 유한 시간 효과 뒤·절 연결 효과 앞에 계산하고 단계마다 버림한다. 사막 지역은 세 공략 중 하나 이상이어도 한 번만 적용한다. 비정형 내부의 완료/진행만으로 유한 시간 공략을 만들지 않는다. 스핑크스에는 추가 피해 감쇠·면역·강제 다회 공격을 넣지 않았다.

기본 28장·고정 have·실습 40/126·기존 교환/준비/형태·혼합 보상·턴 재화·첫 룬·고점·골렘·문지기·두 상점·운영 카드 복귀는 유지한다. Stage 5 상점·새 룬·운영 강화·외부 AI/번역 API/서버를 추가하지 않았다. package-lock은 앱 루트 버전 두 곳만 바뀌었고 의존성 버전은 동일하다.

## 저장과 구조

Grammar → Scoring → Rune → Stage → Presentation 경계를 유지한다. `RunController`만 상태를 커밋하고 봉인 제안은 실제 첫 손패/다음 턴 경계에서만 생성한다. 봉인은 별도 카드 영역이 아니며 기존 DRAW/HAND/SENTENCE/DISCARD/EXHAUSTED 보존식을 유지한다. 안전 저장은 원래 허용 범위를 넓히지 않는다.

0.4 이하 저장은 원래 언어·점수·룬·HP·카드·상품·보상·RNG·완료 경계를 사용한다. 시작 생성기 0.4와 그 어휘 조회를 고정해 새 문법 데이터가 시작 덱/RNG를 바꾸지 않게 했다. 새 0.5 원정만 22전투로 진행한다. 개인 기록은 과거 집계를 보존한 읽기 전용 교육 재검토와 현재 원정의 실제 해금을 분리한다.
