## 중간 실패와 기대값 변경

- 구버전 assertion이 최신 기본 registry/배수를 참조해 실패했다. 테스트에 명시적인 과거 language/controller 계약을 넣었다. 기존 문법·점수 assertion은 보존하고 새 버전 검사를 추가했다. 변경 전 main에서 만든 독립 golden의 원본 분석·공격 결과 및 네 어휘 모드 덱/RNG를 deepEqual로 대조했다.
- 주절 VP를 첫 보조동사 위치로 찾던 초기 구현은 본동사 위치가 다른 복합형/관계절에서 실패했다. lexical head로 주절을 식별하도록 고쳤고 회귀 사례를 추가했다.
- 실습의 명세상 기대값만 새40/126·HP37·gate40/70/126으로 바꿨다. 옛 저장30/87은 별도 검사한다. HEAVY 연출 fixture는 의도한 강도50을 유지하도록 옛2.2 점수 계약을 명시했다.

- 10,000 덱 최초 검사 종료1: 옛 무작위 실습이 새 형태가 늘어난 registry를 암묵 참조했다. 옛 계약0.2.2를 명시하고 같은6장 안의 SV+be/형용사 assertion을 유지했다. 새 일반 손패도 별도로10,000개 추가해 최종 종료0을 확인했다. 초기 보고서는 중도50실패 제한으로 전체10,000개를 완료하지 않았으므로 통과 실적으로 세지 않는다.

## 남은 범위와 검토 순서
