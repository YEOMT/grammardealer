- Gate A — 완료: 새 Vanilla JS + ES Modules + Vite 프로젝트, 순수 데이터 계약, Controller 단일 커밋, 고정 lockfile과 개발·빌드 실행.

- Gate E — 완료: 로컬 프로필·IndexedDB 3슬롯, 저장 검증·원자적 정산·중복실적 방지, 한국어 문서, 임의 하위경로 배포 빌드, 초기 로드 뒤 오프라인 세 전투 및 저장, 소스·배포 ZIP. 최종 검사 수치와 화면 범위는 TEST_REPORT에 기록.
