# 알려진 한계와 미구현 범위

이 문서는 설계상 범위, 현재 구현의 한계, 별도 실기기 검증을 구분한다. 실제로 실행한 검사의 결과와 확인된 결함은 `TEST_REPORT.md`의 최종 기록을 기준으로 한다. 테스트 통과가 모든 영어·모든 기기에서의 동작을 보증하지는 않는다.

## 현재 구현의 한계

| 항목 | 현재 상태 / 영향 |
| --- | --- |
| 제한된 영어 세계 | 등록된 어휘·형태·대표 현재형 용법을 유한한 탐색으로 판정한다. 범용 영어 교정기나 모든 자연스러운 표현의 판정기가 아니다. |
| 고급·미등록·불확실한 입력 | 지원을 확인하지 못하면 `UNSUPPORTED`로 돌려보낸다. 미지원 문장을 문법적 오답으로 단정하거나 보너스를 지급하지 않는다. |
| `recently` | 제작목록에는 있지만 현재형 기본 범위에서 대표 용법 검증이 충분하지 않아 시작 덱·보상에서 제외했다. 과거·완료 Pack 검증 후 활성화할 후보다. |
| 어휘 수준 | 초급/기본/심화/자유는 이 게임의 초기 큐레이션 밴드다. CEFR·교육과정 인증 등급이나 학습 효과 검증 결과가 아니다. |
| 자동 플레이 정책 | 제한된 현재 손패 후보 검색은 인간의 전략이나 전체 seed의 승률을 증명하지 않는다. 덱 구조 검사와 실제 전투 시뮬레이션을 구분한다. |
| 저장 | 같은 브라우저·사이트 주소의 IndexedDB다. 사이트 데이터 삭제·브라우저 정책·시크릿 모드·저장 실패의 영향을 받을 수 있다. 실패 시 메모리 플레이는 가능하지만 저장 성공으로 표시하지 않는다. |
| 로컬 프로필 | 닉네임은 표시용이다. 로그인·비밀번호 보호·클라우드 계정·다른 기기 동기화는 없다. |
| 글꼴·이모지 | 운영체제 로컬 글꼴/이모지를 사용한다. OS별 외형이 다르며 한글 글꼴이 없는 Linux에서는 로컬 글꼴 설치가 필요하다. |
| 작은 세로 화면 | 가로 화면을 권장한다. 모바일 세로 전체 지원을 완료했다고 주장하지 않는다. |
| 실행 방식 | 정적 서버 또는 GitHub Pages에서 실행한다. 로컬 HTML 더블클릭 `file://`는 지원 대상이 아니다. |

## 별도 검증이 필요한 환경

- 실제 iPad의 Safari 터치·드래그·회전·오디오: **NOT RUN**. Chromium 터치 에뮬레이션이나 화면 크기 검사를 실제 iPad 검사로 계산하지 않는다.
- 실제 저사양 학생 기기의 장시간 플레이·프레임·배터리·오디오 지연: **NOT RUN**.
- Firefox/WebKit 전체 호환성 및 학교의 실제 기기/브라우저 정책: **NOT RUN**.
- 사용자 계정의 실제 GitHub Pages 게시: **NOT RUN**. 공개 업로드는 수행하지 않았으며, 정적 빌드와 로컬 서버 검사 결과는 별도로 기록한다.

## 명세상 후속 범위 — 0.1의 고장으로 분류하지 않음

| 기능 | 상태 |
| --- | --- |
| Stage 2~10, 별도 최종전, 총 48전투, 무한 모드 | OUT OF SCOPE |
| 4·5형식, 과거·진행·완료·수동·관계절·to부정사·가정법 등 | OUT OF SCOPE; 현재 제출은 안전한 미지원 처리 |
| 상점 구매·서비스·Stage 2 진입 | OUT OF SCOPE; 상점 6회 위치 계약만 유지 |
| 초기 10종 밖의 룬 실제 효과 | OUT OF SCOPE; 해금 메타가 있어도 활성 풀에서 제외 |
| 황금·공명 특수 카드 효과 | OUT OF SCOPE; 현재 실제 강화는 연마 +1~+3 |
| 다른 캐릭터, 난이도 2~5, 다회차 면역 보스 | OUT OF SCOPE |
| Firebase·서버 랭킹·Top 100·온라인 멀티플레이 | OUT OF SCOPE |
| PWA 설치·Service Worker·오프라인 재시작 | OUT OF SCOPE |
| 완성형 그림·BGM 제작, 네이티브 앱 포장 | OUT OF SCOPE |

현재 페이지에 필수 자원을 로드한 뒤 네트워크를 끊고 진행하는 것과, 브라우저를 닫고 오프라인에서 다시 실행하는 것은 다르다. 후자는 브라우저 캐시가 우연히 남아 있더라도 0.1이 보장하는 기능이 아니다.
