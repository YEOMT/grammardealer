# Syntax Atlas 0.9.0 변경 내역

- 새 원정에 몽환의 대서고 5전투(38~42)를 추가했다. 잉크 나비 → 올빼미 사서 → 호기심 많은 요정 → 속이 빈 인형 → 도서관장 순서이며 마지막 보상 뒤 STAGE9_END로 끝난다. 새 상점·Stage10·스토리 완주 판정은 없다.
- what 명사절, whether 유한절, 검수된 It + be + 형용사 + to/that 진주어를 실제 파서에 연결했다. 기존 where/when 간접의문문, that 및 생략된 내용절을 재사용한다. 구문 내부 오류와 바깥 오류를 분리한다. what을 수식 관계절로 중복 처리하거나 새 독립 배수를 만들지 않는다.
- 일반전 빙정은 실제 WORD 사본으로 이동·교환·제출하며, 정상 정산된 비문 제출도 한 번 소멸한다. 9-4 지원은 영구 보유 여부로 결정한다. 도서관장에게는 빙정·임시 운영·무료 영구 카드를 주지 않는다. what/whether는 9-1 보상 전 해금한다.
- 도서관장은 HP3000, 살아 있는 턴 종료에 부족분만 최대1000 회복한다. 유효한 명사절/가주어 구문의 양수 피해는 그 턴만 회복을 저지한다. 준비도 턴 종료이며 무턴 조작은 제외한다. HP0과 마지막 턴 승리가 우선한다. RunController가 영수증을 한 번 커밋하고 화면은 피해→회복/저지만 재생한다.
- 새 0.9 원정의 Stage1~8 보스 HP는 400/800/840/1200/1300/1600/1900/2200이다. 골렘은3×280이며 초과 피해가 이월되지 않는다. 기존 일반 적과 28장 시작 덱·전투 자원은 유지했다.
- rune.longSentence는 같은 레벨·배율의 희귀 다이아몬드 룬이다. 모든 등급이 유효한 룬 추첨은194:97:9 가중치(희귀3%, 나머지 일반:고급2:1)를 사용한다. have/that 희귀, to/make/help/be/want 고급, 은빛/금빛 세공과 운영 카드 외형을 맞추고 help 배지를 왼쪽 위로 분리했다.
- Stage9 고정 학습 안내와 실제 제출 기반 명사절 도감을 연결했다. 구버전 기록을 다시 정산하지 않는다. 구버전 원정은 원래 언어·HP·상품·보상·RNG·완료 경계를 사용한다.

검증용 초깃값은 일반HP1700/1800/1900/2000, 지역×1.25, 신규what/whether 고급, 일반전 빙정1/(1+1)/1/미보유that·it·to각1이다. 사용자 확정 난이도 수치로 취급하지 않는다. 최종 원화·BGM은 미제공이며 기존 이모지/스타일을 사용한다.

실제 결과와 남은 검증 범위는 [검증 보고서](TEST_REPORT_0.9.md), [90개 인수 조건](ACCEPTANCE_0.9.md)을 따른다. 자연 보상 42전투 완주를 지정 상태 검사로 대체하지 않는다.
