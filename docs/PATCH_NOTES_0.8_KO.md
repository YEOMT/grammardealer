# Syntax Atlas 0.8.0 변경 사항

기준은 작업 시작에 fetch한 `origin/main`의 `ca1675dbb9e546bf2b9442dba8cfc1077c7e12dd`다. 새 원정만 8지역 37전투 / `STAGE8_END`로 확장한다. 기존 저장은 해당 버전의 종료 경계와 언어·수치·보상·상점·RNG를 유지한다.

- Stage 8 고대의 수로도시: 주격 관계절 → 목적격·생략 → 관계부사 → 기존 시제·태와 관계절 → 청동 수문장.
- 입장 시 `who / which / 받지 않기`를 한 번 고른 뒤 네 번째 상점으로 이동한다. 이미 보유해도 선택할 수 있으며 NONE은 무보상이다. Stage 8 that 자동 지급은 없다.
- 8-3에만 where·when 빙정 WORD를 한 장씩 공급한다. 일반 WORD 이동·교환·운영을 따르며 실제 제출 시 깨지고 전투 종료에 제거된다. 영구 덱과 결정 보스의 카운터에 들어가지 않는다.
- 관계대명사·목적격 생략·전치사 목적격·관계부사와 직접/간접 의문문을 실제 구조로 분석한다. 카드 역할을 미리 고르거나 숨은 do/be/that을 생성하지 않는다.
- 관계절 콤보는 원정 해금 후 계열 전체 ×2 한 번, Stage 8 지역 ×1.25 한 번이다. 새 질문 전용 콤보는 없으며 기존 문형·시제·룬을 사용한다.
- 청동 인장은 한 번의 정상 양수 피해 제출에 **서로 다른 주격·목적격 관계절 노드**가 함께 있을 때만 해제한다. 생략 목적격도 인정한다. 이전 공격 실적을 모으지 않으며 잠금 중 HP 1과 overkill 0을 지킨다. 조건을 만족한 공격부터 처치 가능하고 다시 잠기지 않는다.
- 실제 제출 후 선행사 연결선·관계절 역할·생략 표시, 별도 질문 구조 기록, 새 도감 3항목을 추가했다. 도시의 남청색·수로 반사·청동 장식은 기존 카드·조작 배치를 유지한다.

28장 시작 덱, 6턴, 교환·드로우·16칸·4룬, 기존 7지역 HP·점수·룬·운영 7종·실습·개인 기록은 유지한다. 새 HP 1280/1360/1440/1520/1600, 관계절 배율·새 WORD 등급·일반 적 이름은 첨부 명세의 **구현 초깃값**이며 사람의 난이도 검증 완료값이 아니다. 새 룬·Stage 9·새 서버·외부 번역/AI는 없다.

package/lockfile은 프로젝트 버전만 0.8.0으로 올리고 의존성 버전과 integrity는 유지했다. `test:browser:waterways`, `test:e2e:waterways`, `test:runs:waterways`, `test:decks:waterways`를 추가했다. 실제 결과와 한계는 [검증 보고](TEST_REPORT_0.8.md), [인수표](ACCEPTANCE_0.8.md)를 따른다.
