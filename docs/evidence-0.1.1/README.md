The original Work evidence and the Windows baseline evidence remain in the preserved local handoff source. They are historical results, not results from a fresh clone. Current migration and UI validation results are summarized in `../SOURCE_MIGRATION_REPORT.md`. Raw execution logs and duplicate captures are retained locally, outside Git.
