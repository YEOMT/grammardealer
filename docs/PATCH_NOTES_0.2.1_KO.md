# 0.2.1 패치 노트

- Stage 1-1을 한 번 완료하는 필수 실습으로 변경했다. be/happy 조합과 회수, run 교환, I 순서 변경, 실제 오류 공격, 정보 패널, 준비, run→runs 형태 선택을 진행한다. 두 공격은 기존 엔진의 30/87이며 강제 처치를 하지 않는다.
- 점수 40/60/87에서 실제 이벤트를 읽고 확인한다. 설명 대기와 숨겨진 탭은 연출 제한 시간에서 제외한다. 중단한 연출은 같은 확정 결과 재생 또는 실습 재시작/나가기로 복구하며 피해·정산을 다시 적용하지 않는다.
- 완료할 때 정상 28장 덱과 원래 RNG/통계/사전을 복원한 후 첫 보상을 생성한다. 실습 자체는 개인 문법 기록·최고 피해·해금을 올리지 않는다. 승리 2 + 남은 턴 3의 재화 5는 한 번 지급한다. 다음 원정은 정상 랜덤 전투이며 설정에서 별도 실습을 열 수 있다.
- 버리기 체크를 카드 footer에 통합했다. 본문과 체크의 클릭 영역을 분리하고 체크에 44×44 영역·키보드 포커스를 유지한다.
- 충돌 위치에서 짧게 멈춘 뒤 문장과 적 영역에 반동을 준다. 강도는 최대 HP 기준 위력 비율을 사용하며 처치만으로 가장 강해지지 않는다. 낮은 충돌음과 유한한 처치 퇴장 연출을 추가했다. 효과 감소는 숫자 읽는 시간을 줄이지 않는다.
- 새 0.2.1 원정의 초원 HP는 77/132/242. 0.1.0은 70/120/220, 0.1.1/0.2.0은 91/156/286을 유지한다. 항구 HP·장막·가격·보상·룬 배율은 바꾸지 않았다.
- fast 부사는 실습/샌드박스 언어 자료에만 추가했다. 일반 시작 덱·보상·상점과 이전 버전 후보에는 포함하지 않는다. 문법 엔진은 실제 very+fast 수식 구조를 분석한다.

기존 IndexedDB 이름·3슬롯·게임/저장소 이름·배포 경로와 의존성 버전은 유지한다. package/lock의 앱 버전만 0.2.1로 맞췄다. 이번 작업은 PR 제출까지이며 main 병합·공개 배포는 하지 않는다.
