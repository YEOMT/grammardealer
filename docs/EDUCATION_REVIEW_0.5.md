0.5 UI 집중 실행: `.local-validation/v05/desert-browser-development-03/report.json`, **29 PASS / 17 캡처 / Chromium 동영상**. 앞선 실행의 1366×768·손패14 최대 배치에서 봉인 표식 높이로 버리기 조작부가 12px 넘친 실제 UI 실패는 손패 콘텐츠 높이 확보와 편집 대기 공간/상태 여백 재배분으로 수정했다. 카드·버튼 크기와 검사 기준은 유지했다. 두 번째 실패는 닫힌 dialog 제거 이벤트를 기다리기 전에 다음 형태 메뉴 검사가 시작된 도구 타이밍 문제였다. 닫힘 완료를 기다린 뒤 같은 단일 Form 검사에 통과했다. 최종 공식 묶음 재실행 결과는 통합 보고서를 우선한다.

후속 독립 검토에서 새 단어의 보상 연마·제거 대상 보기와 연마 완료 창이 기본 0.3 레지스트리를 읽는 누락을 확인했다. 해당 두 호출에 원정 버전을 전달하고, 개발 전용 샌드박스의 두 카드 보기 호출에도 현재 `LANGUAGE_VERSION`을 전달했다. `.local-validation/v05/desert-service-regression/report.json`은 **36 PASS / 20 캡처 / errors 0**이다. 실제 앱의 IndexedDB 불러오기 → enjoy/finish/hobby 제거 대상 표시·취소 → 연마 확정·10→15 표시 → 다음 전투 입력과 개발 샌드박스의 enjoy/read/reading을 확인했다. 초기 카드 소유와 승리용 카드는 명시적인 지정 fixture이며 자연 원정 보상 획득으로 보고하지 않는다.

같은 후속 실행의 `role-16.png`는 `you`를 바깥 목적어, `to read books`를 전체 목적격보어, `books`를 준동사구 내부 목적어, `read`를 비정형 동사구로 표시한다. `read` 단독을 보어로 표시했던 분석 역할은 별도 parser 회귀로 수정된 결과다. `capacity-1366-14.png`와 새 단어 연마 캡처도 직접 시각 검토했다. 앞선 중첩 실행 `.local-validation/v05/desert-browser-version-routing/`의 6검사 후 중단은 파일 반영과 Vite reload가 겹쳐 지정 화면이 사라진 실행 환경 실패로 보존했다. 이후 동결된 소스의 36검사 실행으로 재검증했으며, 이 실패를 통과 결과에 포함하지 않는다.
