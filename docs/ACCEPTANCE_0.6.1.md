# Syntax Atlas 0.6.1 인수 조건 실행 기록

최소 증거 수준을 채운 항목만 PASS다. 코드·단위·Controller가 통과했어도 요구된 실제 브라우저/저장/캡처가 아직 없으면 **NOT RUN**이며, 실행된 부분은 근거 칸에 따로 적었다. 첨부 JSON은 요구사항을 식별하는 데만 사용했고 통과 기록으로 사용하지 않았다.

최종 집계: **PASS 139 / FAIL 0 / NOT RUN 0**, 총139항목. 최종 단위1047·데이터2962·빌드·설원 opening10000, 공식 browser14묶음291·polish49·cross92, 신규 집중 UI74/66캡처·추가 UI 경계20/5캡처·대비84, 실제 production27전투와 별도의 6-1~6-3 학습 코스 증거를 반영했다. A043의 실제 production-main 잠금 경계3검사/2캡처도 포함했다. 이 집계는 테스트 개수나 전체 개발 완료율이 아니다.

UI 방법·한계는 [UI 검토](UI_THEME_REVIEW_0.6.1.md), 실제 기반·명령은 [검증 보고서](TEST_REPORT_0.6.1.md), 운영97개는 [실행 JSON](validation/v0.6.1/operation-progression-results.json), 문법62개/회귀455개는 [문법 결과](validation/v0.6.1/grammar-results.json)에 연결한다. 로컬 원본 로그는 `.local-validation/v061/`에 보존하며 공개 문서에는 개인 절대 경로를 넣지 않는다.

`UNIT_AND_CONTROLLER`는 지정 상태의 실제 명령을 포함한다. `CONTROLLER_AND_BROWSER`, `UNIT_STORAGE_AND_UI`, `UNIT_CONTROLLER_AND_BROWSER`, `UNIT_STORAGE_AND_BROWSER`, `GRAMMAR_CONTROLLER_AND_UI`, `UNIT_NUMERIC_AND_UI`, `BROWSER_GEOMETRY_AND_CAPTURE`는 각각 브라우저/UI 근거까지 필요하다. 지정 카드를 쓴 UI와 자연 원정 UI는 같은 증거가 아니다.
