## 변경
- 손패 너비 1.25배, 높이 약 1.25배 이상. 한 줄·측정 기반 페이지 유지. 조합대 카드 크기와 12×2/24장 한도 유지, 한/두 줄 그룹 중앙정렬.
- `턴 넘기기`는 기존 PREPARE 그대로. `조합대 비우기`는 RunController의 원자적 CLEAR_SENTENCE로 실제 손패 빈자리만큼 오른쪽부터 회수한다. 빈 손패 공간 0이면 상태 변경 없이 안내한다.
- 회수 사본/연마/임시 속성/선택 형태 보존. 형태는 편집 세션 캐시로 재배치 때 전달하며 이후 폐기한다. 기존 저장 형식에 새 필드를 추가하지 않았다. 턴 진행·불러오기 후 손패의 편집용 형태 미리보기는 기본형으로 돌아간다.
- 버리기/선택 해제를 버린 더미 왼쪽 위로 이동. 사용 완료 상시 버튼만 제거; 운영 카드 처리 및 기록 유지.
- 실제 PC 진단에서 공격 복제 행이 flex→block으로 바뀌고 카드 크기가 달라지는 현상 확인. body 오버레이에 기존 responsive 스타일 문맥과 보드 변수를 전달하여 복구. 충돌/피해/종료 정산은 변경하지 않았다.
- 지역 정보 상시 표시, 몬스터 목록은 이름과 해당 원정 HP만 표시. 입장·선택을 하단에 배치하고 하늘섬 선택 화면을 컴팩트하게 조정.
- 앱/package 0.10.3, 원정·저장 정책 버전은 0.10.2 유지. lockfile은 루트 버전 문자열 2곳만 변경, 의존성 변경 없음.
